## MODIFIED Requirements

### Requirement: 单一资料库根目录与本地持久化

系统 MUST 允许用户选择一个活动资料库根目录，并在本机持久化根目录逻辑 ID、相对路径和歌曲记录；一期同一时刻只能有一个活动根目录。资料库数据库 MUST 只保存在应用数据目录；资料库根目录可保存不含本机路径或凭据的 `echo/` 可携带控制面，但不得把本机绝对路径、数据库文件或凭据作为远端资料的一部分（一期不提供远端同步）。

#### Scenario: 选择根目录并建立资料库
- **WHEN** 用户选择一个可读的目录作为资料库根目录
- **THEN** 系统创建或打开该资料库的本地记录，读取或建立稳定的根目录逻辑 ID，并开始扫描；重启应用后仍使用同一逻辑 ID 和歌曲 UUID；目录不可写时仍允许浏览和播放，但明确禁用导入与删除

#### Scenario: 安全切换活动根目录
- **WHEN** 已存在可用活动根目录且用户选择另一个可读目录
- **THEN** 系统先验证并扫描新目录，成功后才将其设为唯一活动根目录；系统不移动或删除旧目录文件，保留旧根目录的逻辑记录，并在用户重新选择同一路径时复用原逻辑 ID

#### Scenario: 切换根目录失败
- **WHEN** 新目录验证或首次扫描无法建立可用资料库
- **THEN** 系统继续使用此前的活动根目录和可用视图，不用失败配置覆盖原配置

### Requirement: 扫描、监听与手动重扫

系统 MUST 扫描 `media/` 及其子目录中的一期支持音频格式，解析每个文件并建立或更新记录；运行期间 MUST 监听新增、删除、移动和修改，并提供可重复执行的手动重新扫描。扫描 MUST 忽略资料库根目录中 `media/` 以外的所有内容，包括 `echo/`（及 `echo/tmp/`）；扫描结果 MUST 可报告已发现、已更新、已删除、跳过和失败的数量及错误原因。

#### Scenario: 首次扫描发现支持文件
- **WHEN** 用户确认具有 `media/` 的根目录并触发首次扫描
- **THEN** 系统仅递归发现 `media/` 下的支持格式文件，逐文件解析并持久化歌曲记录，扫描完成后可在曲库检索这些歌曲

#### Scenario: 忽略不支持文件
- **WHEN** 根目录包含图片、文档或未列入一期格式矩阵的文件
- **THEN** 系统不创建歌曲记录，不移动或修改该文件，并在扫描结果中将其作为跳过项而非失败歌曲

#### Scenario: 忽略控制面目录
- **WHEN** 根目录包含 `echo/`（包括 `echo/tmp/`）及其任何内容
- **THEN** 系统不将控制面或暂存内容创建为歌曲记录，也不移动或修改其文件

#### Scenario: 不兼容旧资料库布局
- **WHEN** 用户选择的目录只包含旧布局的根目录艺人文件夹且不存在可扫描的 `media/`
- **THEN** 系统明确要求用户建立新的资料库或重新导入媒体，不扫描旧布局、不迁移歌曲 UUID 且不创建旧路径歌曲记录

#### Scenario: 监听外部新增和修改
- **WHEN** 资料库运行中新增支持音频、删除音频、移动音频或修改音频内容
- **THEN** 系统在监听事件稳定后更新对应记录和搜索索引；事件丢失或无法确定变化时，用户可通过手动重扫得到同样的最终状态
