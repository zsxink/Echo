## Context

`has_media_dir` 的目录判断在保护检查前运行。Windows 目录和文件符号链接有独立创建类型；默认文件型夹具不是目录测试所需场景。

## Goals / Non-Goals

- 让 Windows、macOS、Linux 的既有文件和目录符号链接测试以等价的输入覆盖产品行为。
- 不修改生产扫描逻辑、产品规格、CI 矩阵和现有错误断言。

## Decisions

读取既有测试目标的元数据，确认它是普通文件或目录。Windows 仅在目录分支添加 `/D`；Unix 保留 `ln -s`。创建成功后，先用不跟随链接的元数据验证链接本身，再用跟随链接的元数据验证文件或目录种类。保留既有无法创建链接时的跳过能力；成功但形状不匹配必须失败，不能静默跳过。没有新增依赖、公开接口、跨层引用或失效实现。
