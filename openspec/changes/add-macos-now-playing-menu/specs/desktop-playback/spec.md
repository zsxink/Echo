## MODIFIED Requirements

### Requirement: 后台与托盘控制
系统 SHALL 支持关闭主窗口后按本机偏好退出应用或保持后台运行；后台运行时 macOS 提供菜单栏状态项与系统 Now Playing 集成，Windows/Linux 提供系统托盘入口，入口 SHALL 能查看当前播放状态、控制播放、显示主窗口或退出应用。macOS 系统 Now Playing 集成 MUST 使用唯一桌面播放会话发布当前项的安全展示信息，并将系统播放、暂停、上一首和下一首命令路由到该会话；菜单栏状态项仍为独立的 Echo 后台入口。

#### Scenario: 关闭窗口退出
- **WHEN** 用户将“关闭主窗口时”设置为退出应用并关闭主窗口
- **THEN** 系统停止播放并退出进程，不保留后台托盘控制或 Echo 发布的系统 Now Playing 状态

#### Scenario: 关闭窗口后台运行
- **WHEN** 用户将偏好设置为保持后台运行并关闭主窗口
- **THEN** 系统保持播放与进程运行，显示对应平台的菜单栏状态项或系统托盘入口；macOS 继续发布与当前会话一致的系统 Now Playing 信息并响应系统传输控制

#### Scenario: 托盘控制
- **WHEN** 用户从菜单栏状态项或系统托盘入口操作播放控制、查看状态、显示主窗口或退出
- **THEN** 系统执行对应操作并保持播放会话、主窗口状态、平台入口和 macOS Now Playing 状态一致
