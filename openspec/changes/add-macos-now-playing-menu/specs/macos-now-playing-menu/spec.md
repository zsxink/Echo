## Purpose

让 Echo 将唯一桌面播放会话安全发布给 macOS 的系统 Now Playing 服务，从而由控制中心显示歌曲信息并把系统媒体控制可靠地路由回播放器。

## ADDED Requirements

### Requirement: Echo 向 macOS 发布系统正在播放信息
系统在 macOS SHALL 将 Echo 唯一桌面播放会话的当前歌曲发布给系统 Now Playing 服务。存在可播放当前项时，发布信息 MUST 包含歌曲标题、可用艺人和专辑、时长、有效播放进度、播放速率/状态以及可用封面；这些字段不得包含资料库绝对路径。临时播放项也 MUST 发布其已知展示元数据，但不得伪造不存在的资料库字段。

#### Scenario: 发布有封面的资料库歌曲
- **WHEN** Echo 开始或切换到具有可用内嵌封面的资料库歌曲
- **THEN** 系统 Now Playing 信息包含该歌曲的标题、艺人、专辑、时长、进度、播放状态和封面，供 macOS 控制中心按系统规则展示

#### Scenario: 封面或部分元数据不可用
- **WHEN** 当前歌曲没有封面，或艺人、专辑等可选元数据缺失
- **THEN** 系统发布仍然有效的标题、时长、进度和播放状态，省略不可用字段而不使用文件路径、陈旧封面或伪造内容

#### Scenario: 播放临时文件
- **WHEN** Echo 播放资料库外的临时音频文件
- **THEN** 系统发布该项已知的展示名称和播放状态；不会将临时项写入资料库或发布其本机绝对路径

### Requirement: 系统正在播放状态保持准确且可清除
系统 SHALL 在切歌、播放/暂停、seek、自然播放结束、加载失败、会话恢复和显式退出时，使 macOS Now Playing 信息与唯一播放会话一致。播放进度 MUST 位于当前歌曲有效时长范围内；停止且不存在当前项时，系统 MUST 清除 Echo 已发布的当前歌曲信息和活动播放状态。

#### Scenario: 暂停、恢复与定位
- **WHEN** 用户在 Echo、系统媒体键或控制中心执行暂停、恢复或定位
- **THEN** macOS Now Playing 的播放状态、速率和有效进度更新为与 Echo 播放会话一致的值

#### Scenario: 切歌、恢复与退出
- **WHEN** Echo 切换歌曲、自然结束、恢复保存会话或用户显式退出应用
- **THEN** 系统替换为当前项的正确信息，恢复项保持暂停；没有当前项或退出时清除陈旧歌曲信息

### Requirement: Echo 处理 macOS 系统远程传输命令
系统在 macOS SHALL 注册播放、暂停、上一首和下一首系统远程命令，并将每个有效命令转发到 Echo 唯一桌面播放会话。命令处理结果 MUST 如实反映是否接受；系统命令不得创建第二个播放器、窗口或队列。

#### Scenario: 控制中心控制播放
- **WHEN** 用户在 macOS 控制中心的 Now Playing 模块选择播放、暂停、上一首或下一首
- **THEN** Echo 对唯一播放会话执行一次等价操作，并用更新后的系统 Now Playing 信息确认结果

#### Scenario: 无法执行的系统命令
- **WHEN** 没有当前可播放项、队列没有上一首/下一首，或播放器拒绝系统远程命令
- **THEN** Echo 向系统返回失败或不支持结果，不创建新的播放会话，也不将状态伪报为成功

### Requirement: 系统展示由 macOS 管理
Echo SHALL 发布系统定义的 Now Playing 元数据和命令能力，但 MUST NOT 尝试修改 macOS 控制中心的布局、图标排序或展示时机。现有 Echo 菜单栏控件与系统 Now Playing 模块为独立入口，二者使用同一播放会话并保持状态一致。

#### Scenario: 系统决定展示布局
- **WHEN** macOS 选择在控制中心或其他系统媒体控件中展示 Echo 的 Now Playing 信息
- **THEN** Echo 提供完整且安全的元数据与命令处理，接受由 macOS 决定最终布局和展示形式
