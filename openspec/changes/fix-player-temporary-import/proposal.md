## Why

从系统文件浏览器打开的临时歌曲可以在常驻播放栏中导入，但播放栏当前没有等待导入完成、刷新资料库或接收导入结果的闭环。用户会看到旧的资料库列表，能够重复点击导入，而且当前播放仍停留在不可收藏、不可入队的临时项上。

## What Changes

- 将常驻播放栏的临时歌曲导入改为可等待的请求，导入期间显示“导入中…”并禁用按钮。
- 导入成功或识别为重复歌曲后，自动失效并刷新当前资料库列表与侧边栏计数；失败或跳过时保留可理解的结果反馈，不误刷新为成功。
- 导入结果带有目标 `SongId` 时，将当前播放队列中的临时项替换为对应的库内歌曲，并保持原有播放/暂停状态与当前播放位置。
- 为播放栏导入、资料库刷新广播、队列替换和失败路径补充回归测试。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-playback`: 临时播放项显式导入后转为对应的资料库播放项，并保持播放会话连续。
- `library-experience`: 播放栏导入完成后资料库列表与导航计数自动刷新，且导入控件具备加载保护。

## Impact

- 影响 `apps/desktop` 的常驻播放栏、资料库查询刷新状态和组件测试。
- 影响 `apps/desktop/src-tauri` 的临时导入 command 与 `echo-desktop` 播放 coordinator；不改变 Tauri command 名称或 IPC 返回 DTO 结构。
- 不增加数据库 schema、Core 依赖或跨平台文件协议；导入仍复用既有导入用例和结果类型。
