## ADDED Requirements

### Requirement: 首次导入后资料库与播放栏显示选中歌曲

系统 SHALL 在空资料库成功导入第一首歌曲后，将该歌曲设为默认选中歌曲并同步到常驻播放栏，使播放栏从空状态变为显示该歌曲的可辨识信息；该状态 MUST 不自动播放歌曲，也不得把导入操作解释为用户点击播放。

#### Scenario: 导入第一首歌曲
- **WHEN** 资料库此前没有歌曲且用户成功导入一首受支持音频
- **THEN** 系统将该歌曲设为当前选中/待播放项，常驻播放栏显示歌曲封面、标题和艺人等可用信息，播放按钮仍处于未播放状态

#### Scenario: 首次导入失败
- **WHEN** 第一首音频导入未完成、校验失败或未提交为资料库歌曲
- **THEN** 系统不创建初始播放项，资料库和常驻播放栏继续显示与真实歌曲数量一致的空状态，并反馈导入失败原因

#### Scenario: 已有歌曲时继续导入
- **WHEN** 资料库已有当前歌曲或有效待播放状态，用户再次导入歌曲
- **THEN** 系统不因导入完成而替换当前播放项、不自动播放新歌曲；既有播放队列与播放状态保持不变
