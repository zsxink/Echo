# Spec Delta

## MODIFIED Requirements

### Requirement: 源文件、系统关联与安全边界

导入 MUST 复制外部源文件而不移动、删除或修改源文件。系统 MUST 支持将一期音频格式注册为默认打开应用；从系统文件管理器打开资料库外文件时创建仅存在于当前会话的临时播放项，可解析内嵌信息和同名 `.lrc`，但不得写入歌曲表、歌单、播放统计、同步队列或导入暂存目录。

窗口级投放是另一条外部文件打开入口，MUST 与系统文件管理器双击打开共享同一安全边界：投放 MUST NOT 复制、移动、删除或修改源音频或同名 `.lrc`，MUST NOT 写入歌曲表、`media/`、歌单、播放统计、同步队列或导入暂存目录；需要入库时 MUST 由用户显式使用「导入当前临时文件」入口。投放路径由壳层以已解码的绝对路径交给该通道，MUST NOT 由前端二次解码（与「操作系统文件打开载荷必须先归一化为本地路径」同口径）。文件夹投放 MUST NOT 触发目录扫描、资料库根目录变更或任何复制行为。

#### Scenario: 外部文件直接打开
- **WHEN** 用户从系统文件管理器双击资料库外的支持音频文件
- **THEN** 系统唤醒或启动 Echo，创建临时播放项并播放，可展示内嵌封面/歌词及同名 `.lrc`，关闭会话后该项消失

#### Scenario: 活动资料库内文件直接打开
- **WHEN** 系统传入的音频路径位于当前活动资料库根目录且可通过相对路径找到已有记录
- **THEN** 系统使用该歌曲已有 UUID 播放，不创建临时项，不复制文件，并沿用其覆盖层、收藏和统计语义

#### Scenario: 非活动旧资料库文件直接打开
- **WHEN** 系统传入的音频路径属于已保留但当前非活动的旧资料库根目录
- **THEN** 系统不得使用旧根 UUID 绕过活动根隔离或静默切换资料库，而是将文件作为当前会话临时项播放并提示可在设置中显式切换资料库；该次播放不使用旧根覆盖层、收藏或统计，也不持久化到队列

#### Scenario: 源文件保持不变
- **WHEN** 导入成功、重复或失败
- **THEN** 系统均不修改源音频或源 `.lrc` 的内容、名称和位置

#### Scenario: 暂存目录名称与用户内容冲突
- **WHEN** 资料库中已经存在类似 Echo 暂存目录名称的用户目录、无效所有权 marker 或符号链接
- **THEN** 系统不得忽略、接管、写入或清理该目录，而应 exclusive-create 带有效所有权 marker 的随机专属目录；无法安全建立时禁用导入和删除

#### Scenario: 投放不入库且源文件不变
- **WHEN** 用户把资料库外的受支持音频拖入窗口并松手播放
- **THEN** 源文件内容、名称与位置不变，`media/`、歌曲表、歌单、播放统计、同步队列与导入暂存目录均无新增记录，播放项仅存在于当前会话

#### Scenario: 投放后显式导入才入库
- **WHEN** 投放产生的临时项正在播放，用户使用「导入当前临时文件」入口
- **THEN** 系统沿用既有导入流程完成复制与入库，并把当前 queue entry 转换为资料库歌曲；未执行该显式操作时不得自动入库

#### Scenario: 投放路径不二次解码
- **WHEN** 投放路径为壳层提供的已解码绝对路径，且文件名合法包含 `%20` 字面量、中文或空格
- **THEN** 前端不执行 URL 解码，播放与显示均使用原路径，不出现解码后的错误路径

#### Scenario: 文件夹投放不触发扫描或复制
- **WHEN** 用户把一个含音频文件的文件夹拖入窗口松手
- **THEN** 系统给出可读拒绝提示，不扫描该目录、不登记为资料库根目录、不复制任何文件，资料库内容与当前播放状态均不变
