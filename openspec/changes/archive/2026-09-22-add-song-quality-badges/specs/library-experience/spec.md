## ADDED Requirements

### Requirement: 歌曲音质徽标

系统 SHALL 在歌曲列表行的歌曲名称后,根据歌曲已落库的音频技术参数派生音质档位并显示徽标:满足无损/高解析条件时显示 **SQ**,否则满足高音质码率条件时显示 **HQ**,两者均不满足时不显示徽标。档位 SHALL 在读取时派生,不依赖导入时预计算,不新增持久化字段,对既有歌曲无需重扫即可生效。

档位判定规则(满足其一即归入该档,从高到低判定,SQ 优先于 HQ):

| 档位 | 规则 |
|---|---|
| SQ(无损/高解析) | 格式为 FLAC 或 WAV;或位深 ≥ 24 bit;或采样率 ≥ 96 kHz |
| HQ(高音质) | MP3 码率 ≥ 320 kbps;或 MP4/AAC 码率 ≥ 256 kbps;或 Opus/Ogg 码率 ≥ 256 kbps |
| 无徽标 | 其余情况,包括码率低于上述阈值、音频参数缺失或不可用、文件损坏不可识别 |

#### Scenario: 显示 SQ 徽标

- **WHEN** 用户浏览歌曲列表,且某歌曲为 FLAC/WAV,或位深 ≥ 24 bit,或采样率 ≥ 96 kHz
- **THEN** 该行歌曲名称后显示 SQ 徽标,采用黄色文字,字号小于歌曲名

#### Scenario: 显示 HQ 徽标

- **WHEN** 用户浏览歌曲列表,且某歌曲不满足 SQ 条件,但 MP3 ≥ 320 kbps、MP4/AAC ≥ 256 kbps 或 Opus/Ogg ≥ 256 kbps
- **THEN** 该行歌曲名称后显示 HQ 徽标,采用蓝色文字,字号小于歌曲名

#### Scenario: 不显示徽标

- **WHEN** 用户浏览歌曲列表,且某歌曲既不满足 SQ 也不满足 HQ 条件(例如 128 kbps MP3),或其音频参数缺失、文件损坏不可识别
- **THEN** 该行歌曲名称后不显示任何音质徽标,行布局保持正常

#### Scenario: 同时满足 SQ 与 HQ 条件

- **WHEN** 某歌曲同时满足 SQ 与 HQ 的判定条件(例如 24 bit / 44.1 kHz FLAC)
- **THEN** 系统只显示 SQ 徽标,不重复显示 HQ

#### Scenario: 徽标不影响行操作

- **WHEN** 用户对带徽标或不带徽标的歌曲行执行播放、收藏、加入队列、删除、多选等既有行操作
- **THEN** 所有行操作行为与徽标显示前一致,徽标不响应独立交互、不遮挡歌曲名或操作入口

#### Scenario: 旧歌曲即时生效

- **WHEN** 应用升级后首次加载歌曲列表,歌曲在既有数据库中已有音频参数而未存储任何档位信息
- **THEN** 列表直接根据已落库参数显示正确徽标,无需迁移或重新扫描
