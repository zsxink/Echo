## Purpose

为本机用户 EQ 曲线提供明确保存与复用的预设管理闭环，确保命名、数量限制、删除当前项及原子写入失败有一致可验证的行为，同时与只读内置预设和未来导入能力保持边界。

## ADDED Requirements

### Requirement: 保存独立曲线快照
系统 SHALL 仅通过保存为新项写入 P0 用户曲线，保存当前 EQ 草稿的十段参数和 preamp 模式/请求值，使用独立用户 ID，不覆盖原项。持久化成功后以新 ID 作为当前选择并保留启用/关闭状态，关闭状态保存不得自动启用。草稿不占额度；仅空间处理时 MUST 禁用保存曲线并说明原因。用户曲线与内置预设视觉同级但标记来源。

#### Scenario: 预设编辑保存重选
- **WHEN** 用户选择预设、编辑为草稿、命名保存后再次选择新项
- **THEN** 新项名称/曲线/preamp 与快照一致，原项不变，保存后不再是未保存草稿

#### Scenario: 关闭状态保存
- **WHEN** 用户关闭草稿再保存
- **THEN** 保存成功选择新 ID 但请求保持关闭，播放栏不显示生效名称

#### Scenario: 空间不可保存为曲线
- **WHEN** 当前仅空间预设且未编辑为 EQ
- **THEN** 保存入口禁用并给出需先编辑为 EQ 的原因

### Requirement: 用户名称与额度
系统 SHALL 沿用歌单文本约定：NFKC、首尾与连续空白规整、Unicode 默认 full case-fold 判重，规整后名称为 1–40 个 grapheme cluster 且非空；名称只作文本显示。用户名称 MUST 在所有用户项（包括未来导入项）中唯一并不得与内置显示名同键。用户 ID 与内置 ID MUST 分命名空间。总额度为 50，达到上限拒绝新增并提示清理，重命名不占新额度。

#### Scenario: 名称边界
- **WHEN** 用户提交空白、1/40/41 个感知字符，或 Unicode 等价/大小写/空白规整后重名、内置重名的名称
- **THEN** 仅合法且不冲突的 1–40 字名称可保存，其他输入定位原因并保留输入供重试

#### Scenario: 数量边界
- **WHEN** 用户在已有 49、50 个用户项时新增，或 50 项时重命名
- **THEN** 第 50 项成功、第 51 项被拒绝，重命名允许，草稿不计数

### Requirement: 重命名删除及持久化事务
系统 SHALL 支持用户项重命名和删除；重命名当前项立即更新名称但不重建音频链。删除当前选择 MUST 清选择并关闭处理；删除未选项不改变播放，删除草稿来源不删除草稿。保存/重命名/删除 MUST 持久化成功才报告成功，失败保留原列表、当前状态、输入和草稿并可重试，不影响内置项。

#### Scenario: 管理当前和非当前项
- **WHEN** 用户重命名当前项、删除当前项或删除其他项
- **THEN** 分别仅更新显示名称、清选择并旁路、保持当前播放，各操作只影响目标用户项

#### Scenario: 删除草稿来源
- **WHEN** 用户从某用户预设编辑为草稿后删除来源项
- **THEN** 草稿及其启用请求不变，来源预设被移除

#### Scenario: 写入与播放失败
- **WHEN** 注入新增/重命名/删除写入失败，或删除当前项无法确认安全旁路
- **THEN** 不报告操作成功且不提交新列表/选择，保留输入与草稿供重试；播放侧不能确认回滚时安全旁路并显示实际失败状态，不伪造旧项仍已生效
