## Purpose

提供与音效预设共用状态的固定十段图示均衡器，使用户能安全编辑音色、查看实际滤波响应与前置保护增益，并在关闭、重置、低采样率和快速操作时保持明确且一致的结果。

## ADDED Requirements

### Requirement: 固定频段与实际响应
系统 SHALL 提供 31.25/62.5/125/250/500/1000/2000/4000/8000/16000 Hz 十段，增益范围 -12 至 +12 dB、步进 0.5 dB。P0 固定 peaking 滤波器、Q=√2，不提供 Q/类型编辑，不把中心频率间隔称为所有数字频段的严格实际带宽。响应图 MUST 使用实际有效段的离散滤波系数、处理采样率与实际 preamp 合成响应，不能用推子连线代替或表示设备/空间/动态限幅响应；无音轨时明确标记 48 kHz 参考响应。中心频率 >0.45×equalizer 实际 link 采样率的段 MUST 旁路且禁用编辑，参数仍保留，恢复有效环境后重新应用；未知实际环境保持待应用。为兼容旧 DTO，音效快照可增加可选 `editableBands`（目标 EQ 在当前环境可编辑的频段，不等同于空间链 `activeBands`）和 `responseRate`（响应图所用实际率或明确的参考率）；旧消费者忽略缺失字段，新消费者对缺失字段按现有兼容默认处理。

#### Scenario: 响应与滤波一致
- **WHEN** 用户编辑推子或 preamp 且环境已确认
- **THEN** 响应包含实际前置增益，与客观测量在 design 规定频率范围内误差≤0.25 dB，当前值、可用频段及处理采样率可读

#### Scenario: 低采样率
- **WHEN** 处理采样率为 22.05 kHz
- **THEN** 16 kHz 段禁用且旁路，其保存值不被截断或删除，返回有效采样率后重新应用

### Requirement: 编辑草稿与关闭重置
系统 SHALL 在选择 EQ 时整体替换曲线和 preamp 并请求启用；任一有效 EQ/preamp 编辑创建独立「自定义」草稿、清除预设选中态并请求启用，原预设不变。空间预设时推子显示中性值及替换提示，编辑将移除空间处理。仅切换标签不得改变处理。初始为全零、自动 preamp、关闭、无选择/草稿且开关禁用。关闭已保存预设 MUST 清除选择、保留参数但不创建草稿，开关禁用；关闭草稿 MUST 保留草稿并允许再次启用。重置 MUST 清除选择/草稿并旁路所有新增处理，恢复全零/自动/实际 0 dB，不删除保存项。

#### Scenario: 编辑已保存或空间预设
- **WHEN** 用户编辑已保存预设的推子、preamp 模式或请求值，或从空间预设开始编辑 EQ
- **THEN** 转为独立纯 EQ 草稿并请求启用，无已保存预设选中态，原项保持不变，空间处理不叠加

#### Scenario: 关闭的两种语义
- **WHEN** 用户分别关闭已保存预设与自定义草稿
- **THEN** 前者清选择但保留参数且开关禁用，后者保留草稿且开关可再次启用，播放栏均不显示生效名称

#### Scenario: 重置并收到旧回执
- **WHEN** 用户从任意类型/启用状态执行重置，随后收到旧更新回执
- **THEN** 全零/自动/0 dB 旁路状态保持且开关禁用，旧回执不恢复处理或选中态，保存项仍存在

#### Scenario: 草稿离开与替换
- **WHEN** 用户关闭浮层、切页面/曲目或正常重启，随后选择其他预设或重置
- **THEN** 离开/重启保留草稿和请求状态，选择/重置直接替换草稿不弹确认，未明确保存不创建列表项

### Requirement: 前置增益与不可绕过的削波保护
系统 SHALL 提供自动/手动 preamp，手动请求 -12 至 0 dB、步进 0.5 dB。峰值保护上限 MUST 基于 equalizer 实际 link 采样率的整链增益计算 `safe=-max(0,G)`；手动实际值取请求值与 safe 中更低者，自动初始值为 `safe+0.5 dB`（全零 EQ 特例仍为 0 dB），可低于 -12 dB。自动补偿由不可关闭的末端 limiter 承接；候选包压力捕获 MUST 确认输出 sample-peak≤0 dBFS。处理启用时 MUST 使用浮点余量和不可关闭的输出峰值保护，空间处理也纳入保护，不可先硬削波再衰减或自动提高主音量。界面 MUST 将用户请求值与后端确认的实际值分别呈现，并说明保护限制原因；不得只显示请求值冒充实际值。Auto/Manual 切换 MUST 保留 EQ 增益及手动请求值。保护验收口径 MUST 明确为 sample-peak，不以 -1 dBFS 样本阈值宣称 -1 dBTP true-peak 保证或重建峰值合规；测试记录 true-peak 仅作边界诊断，且注明测量工具/算法，不声称通用重建峰值上界。压力输出 MUST ≤0 dBFS、无非有限值、无非预期硬削波，音量/静音独立。

#### Scenario: 手动零增益不能解除保护
- **WHEN** 单段、多相邻段或全部频段 +12 dB 且手动请求 0 dB，播放接近满幅的正弦/扫频/宽带/反相压力素材
- **THEN** 实际 preamp 被安全限制且明确提示，输出满足峰值门槛，主音量与静音不变

#### Scenario: 空间与旁路保护
- **WHEN** 启用空间感增强，再关闭或重置
- **THEN** 启用期间空间处理及过渡受保护，关闭/重置以实际中间 width 和 preamp 过渡到中性后旁路全部新增处理，不以仅更新内存参数代替原生处理，不改写源文件

#### Scenario: 样本峰值与重建峰值口径
- **WHEN** 压力素材的样本峰值合格但 true-peak 诊断显示不同值
- **THEN** 验收分别记录 dBFS 与 dBTP 和测量工具，不将样本限幅成功描述为 true-peak 合规；产品不新增响度归一化或 true-peak 处理入口

### Requirement: 推子和状态反馈可访问
系统 SHALL 提供有独立高度占位且不重叠的曲线、频率标签、推子、数值、preamp 和保存区域；上下键以 0.5 dB 调节、Home/End 达到边界，读屏名称包含频率/增益/单位，禁用频段有原因。生效、待应用、失败、保护介入 MUST 用文本与语义表达，不能只依赖颜色。预设选择、保存与错误 SHALL 礼貌播报，拖动数值播报 MUST 合并，不逐帧打断聆听。

#### Scenario: 键盘与布局
- **WHEN** 用户仅用键盘/读屏在桌面或窄屏编辑
- **THEN** 所有可用控件可达且焦点可见，禁用段不能修改，面板内滚动可访问保存区，图表和数值不互相覆盖

#### Scenario: 编辑与重配置保护连续
- **WHEN** 在播放中编辑摇滚或混合正负增益曲线、调整手动 preamp，或在音频链重配置后关闭音效
- **THEN** 前置增益随实际中间曲线更新，不先按全部正增益总和骤降再阶跃恢复；逐命令先减少风险再增加风险，重配置后重断言实际滤镜参数，最终以最新请求收敛，应用失败清理所有新增处理
