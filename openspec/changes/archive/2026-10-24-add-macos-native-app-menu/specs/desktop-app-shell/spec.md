## ADDED Requirements

### Requirement: macOS 原生应用菜单与状态项右键菜单

系统在 macOS SHALL 用自建应用菜单替换 Tauri 默认英文菜单：应用菜单（标题 `Echo`）、文件、编辑、播放、视图、窗口、帮助七个中文子菜单，条目文案为中文，应用名严格为 `Echo`。菜单 SHALL 覆盖导入音乐文件、选择资料库目录、重新扫描资料库、设置、播放控制（播放/暂停、上一首、下一首、快退/快进 5 秒、音量增减、静音）、播放模式（顺序播放/随机播放/单曲循环）、六个资料库视图入口、搜索、帮助链接（GitHub 仓库、报告问题），并保留系统标准项（关于、服务、隐藏、退出、关闭窗口、编辑剪贴板、最小化/缩放、全屏）的标准位置。播放类菜单命令 SHALL 与托盘/菜单栏状态项共用同一播放权威通道；「播放/暂停」标签与「播放模式」勾选态 SHALL 与播放栏一致；「视图」勾选态 SHALL 跟随当前工作区视图。菜单栏状态项右键菜单 SHALL 提供显示窗口、导入音乐文件、设置与退出。菜单加速键 SHALL 仅使用修饰键组合，不与工作区裸键快捷键冲突。Windows 与 Linux SHALL 不提供应用菜单栏，托盘行为不受影响。

#### Scenario: 中文菜单替换默认英文菜单
- **WHEN** 用户在 macOS 启动 Echo 并查看菜单栏应用菜单
- **THEN** 菜单栏显示 Echo、文件、编辑、播放、视图、窗口、帮助七个中文子菜单，不出现 File/Edit/View/Window/Help 英文默认菜单；帮助菜单包含 GitHub 仓库与报告问题两个可用条目而非空菜单

#### Scenario: 从菜单导入音乐文件
- **WHEN** 用户选择「文件 → 导入音乐文件…」并在系统文件选择器中确认音频文件
- **THEN** 系统执行与品牌区导入按钮一致的导入流程，侧边栏与歌单计数按导入结果刷新，取消选择器为无操作

#### Scenario: 从菜单选择资料库目录与重新扫描
- **WHEN** 用户选择「文件 → 选择资料库目录…」确认新目录，或选择「文件 → 重新扫描资料库」
- **THEN** 前者走既有目录切换流程并刷新工作区状态，取消为无操作；后者对当前活动根目录执行与设置页一致的重新扫描序列并刷新界面

#### Scenario: 菜单播放控制三处一致
- **WHEN** 播放中用户选择「播放 → 播放/暂停」
- **THEN** 播放状态切换一次，菜单项标签随播放态在「暂停/播放」间切换，且与常驻播放栏、菜单栏状态项图标三处状态一致；上一首/下一首/快退/快进/音量增减/静音条目同样经播放权威通道生效

#### Scenario: 菜单播放模式勾选态一致
- **WHEN** 用户在「播放 → 播放模式」子菜单选择顺序播放、随机播放或单曲循环
- **THEN** 播放模式立即切换，对应菜单条目为唯一勾选态且与播放栏播放模式按钮的当前模式一致

#### Scenario: 菜单视图切换与搜索聚焦
- **WHEN** 用户在「视图」菜单选择全部歌曲/最近添加/喜欢的音乐/歌手/专辑/歌单，或选择「视图 → 搜索」
- **THEN** 前者切换工作区视图且不中断播放，菜单勾选态跟随当前视图（含侧边栏切换后的同步）；后者（`Cmd+F`）聚焦当前工作区搜索框

#### Scenario: 菜单退出保存播放会话
- **WHEN** 用户选择「Echo → 退出 Echo」或按 `Cmd+Q`
- **THEN** 系统保存播放会话后退出进程，不留无法操作的后台入口，下次启动可恢复会话

#### Scenario: 状态项右键菜单补齐
- **WHEN** 用户右键点击菜单栏状态项控件
- **THEN** 右键菜单提供显示窗口、导入音乐文件…、设置…与退出，且导入/设置与主菜单同路径生效

#### Scenario: 菜单动作映射可验证且不影响其他平台
- **WHEN** 在任一平台运行应用菜单决策层单测与前端菜单事件分发测试
- **THEN** 每个菜单语义 id 都映射为唯一的播放命令/前端动作/壳层动作，未知 id 不产生动作；菜单加速键与设置页快捷键表一致且不占用既有裸键；Windows/Linux 构建不含应用菜单代码路径，托盘菜单维持既有结构
