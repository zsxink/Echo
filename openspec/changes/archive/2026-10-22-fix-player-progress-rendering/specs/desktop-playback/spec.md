# Spec Delta

## ADDED Requirements

### Requirement: 播放进度视觉同步

常驻播放栏与沉浸式播放器 SHALL 以一致的播放位置呈现可见进度填充和 seek 控件；播放、暂停、恢复播放及 seek 后两者 MUST 在同一渲染更新中反映权威播放位置，不得持续出现可见偏差。

#### Scenario: 播放期间进度同步
- **WHEN** 歌曲正在播放且播放位置持续推进
- **THEN** 进度填充与 seek 控件保持同步推进，界面其他播放器内容不因逐帧插值反复重绘

#### Scenario: 暂停、恢复与 seek
- **WHEN** 用户暂停、恢复播放或将播放位置拖到新的位置
- **THEN** 进度填充和 seek 控件立即显示同一位置，并按新的播放状态继续或停止推进
