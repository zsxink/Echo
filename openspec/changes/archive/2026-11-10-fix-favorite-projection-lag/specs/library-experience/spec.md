# Spec Delta

## Purpose

修正 LE-R21 中「用户看到的『已保存』反馈 MUST 在目录提交确认后发生，**不等待 SQLite 投影**」这一表述：它与 `library-durability` 新增的「收藏返回前完成读模型投影」直接抵触。收藏是用户单次点击即可感知的写入，返回时读模型必须是新值，否则前端的权威回读会把刚点亮的心形冲掉（issue #152）。

同时把「收藏计数不得因重复操作重复累加」这条用户可观察的结果补进本 capability——计数是界面自己维护的乐观状态，它的前端基线必须取自该歌曲**最近一次已知意图**，而不是可能滞后的渲染行。

## MODIFIED Requirements

### Requirement: 收藏与批量操作以音乐库持久结果为反馈

单曲收藏切换、批量收藏与取消收藏 MUST 在音乐库可靠提交喜欢 true/false 或类型化墓碑之后才更新可见状态；用户看到的“已保存”反馈 MUST 在目录提交确认后发生。**收藏这类用户单次点击即可感知的写入，其返回前的读模型投影 MUST 完成**：返回后立即读取的歌曲列表、喜欢视图与收藏计数已经是该次写入的权威结果，界面因而不得因一次滞后的 SQLite 查询而把已保存的喜欢显示为未收藏。待投影状态可在后台短暂存在，且应通过水位/状态诊断。目录已保存而投影失败 MUST 保留同一操作身份供后台恢复，不得清空用户意图、回退为未收藏或诱导用户再次切换。目录提交本身失败 MUST 视为未保存：乐观更新回退到提交前状态并显示可重试原因。批量操作 MUST 沿现有逐项粒度报告，单项已保存待投影不得计为失败，也不得因其他项失败而回退。收藏从桌面服务命令开始处理至返回已保存结果，在 1,000 与 10,000 首资料库的 Release 验收场景中 P95 MUST 小于 50 ms；测量 MUST 包含可靠目录提交、必要的前台投影追赶和响应构建，并分别记录目录提交与后台 SQLite 投影延迟。完整桌面点击至反馈延迟仍须单独验收。

#### Scenario: 收藏已保存而投影失败
- **WHEN** 用户把歌曲设为喜欢，音乐库已提交而 SQLite 投影暂时失败
- **THEN** 界面显示该喜欢已保存且等待更新，保留同一操作身份，不把按钮回退为未收藏，也不要求用户重新点击

#### Scenario: 正常投影仍在后台时已保存反馈
- **WHEN** 用户收藏歌曲，目录提交已确认但 SQLite 后台投影尚未完成
- **THEN** 界面立即显示已保存结果并按需标示正在更新；服务命令至已保存响应的 P95 小于 50 ms，后续投影完成不会再次改变用户意图

#### Scenario: 收藏未保存
- **WHEN** 音乐库控制面不可写或目录提交失败，而 SQLite 仍可写
- **THEN** 界面回退到提交前的收藏状态，显示可重试原因，且不产生仅存在于数据库的喜欢事实

#### Scenario: 批量收藏部分已保存
- **WHEN** 一次批量收藏中部分歌曲已提交到音乐库、部分失败
- **THEN** 已提交项保持喜欢状态并标注等待更新，失败项单独报告原因，成功项不因同批失败被回退

#### Scenario: 已保存待投影不被当作失败重试
- **WHEN** 用户对处于“已保存，等待更新”的收藏执行重试
- **THEN** 系统按原操作身份恢复投影，不创建第二个喜欢事实或新的事件身份

#### Scenario: 收藏写入返回后界面已是新值
- **WHEN** 用户收藏歌曲，目录提交已确认且收藏的读模型投影随返回完成
- **THEN** 界面立即显示已保存结果，歌曲列表、喜欢视图与收藏计数三处都已是收藏后的值，界面不会因一次滞后的 SQLite 查询而把该喜欢显示为未收藏

## ADDED Requirements

### Requirement: 收藏计数不得因重复操作重复累加

收藏计数的乐观调整 MUST 以该歌曲**最近一次已知意图**为基准，而不是以渲染行中可能滞后的字段为基准。同一首歌在读模型滞后期间被重复以相同意图写入（例如连续两次「喜欢」）时，计数 MUST 只反映该歌曲的一次增量，MUST NOT 因每次写入都基于同一个滞后的旧值而重复累加。

计数 MUST NOT 为负；取消收藏 MUST 相应回退该歌曲的一次增量。

#### Scenario: 同一首歌连续两次喜欢只计一次
- **WHEN** 一首尚未喜欢的歌曲在读模型滞后期间连续两次以「喜欢」写入
- **THEN** 收藏计数相对写入前只增加 1，不因第二次写入基于滞后的旧值而变成 2

#### Scenario: 取消收藏回退一次增量
- **WHEN** 一首已喜欢的歌曲被取消喜欢
- **THEN** 收藏计数相对写入前减少 1，且不会降到负数
