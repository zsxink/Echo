## Purpose

定义一期可日常使用的跨功能验收门槛，确保单项测试通过不再掩盖关键用户流程的断裂或回归。

## ADDED Requirements

### Requirement: 一期日常流程验收基线
系统 SHALL 以可重复执行的自动化检查和必要的原生人工步骤证明一期日常流程可用：用户能在离线状态下选择资料库、浏览或搜索、播放、创建和维护歌单、使用队列回退，并在重启后继续使用。质量门 MUST 包含 Rust 工作区与前端测试；任何已登记测试失败均不得作为一期验收通过。

#### Scenario: 歌单与队列日常流程
- **WHEN** 验收者在可写活动资料库中创建歌单、添加歌曲、播放某首、切换播放模式、回退上一首并重启
- **THEN** 每一步只在提交成功后更新界面，当前队列项持续置顶，三天内历史可回退，重启后资料库、歌单和会话状态可理解地恢复

#### Scenario: 回归质量门
- **WHEN** 变更准备合并或宣布一期验收完成
- **THEN** Rust 工作区测试、前端测试、格式/静态检查及登记的流程场景均通过；播放器加载状态和诊断日志安装不得存在已知失败
