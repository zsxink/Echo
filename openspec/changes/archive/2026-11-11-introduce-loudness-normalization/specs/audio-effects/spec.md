# Spec Delta

## MODIFIED Requirements

### Requirement: 统一预设与一期范围
系统 SHALL 在 macOS、Windows、Linux 提供 `pop`、`rock`、`classical`、`jazz`、`electronic`、`vocal`、`bass`、`warm`、`retro` 九个只读 EQ 预设，以及 ID 为 `surround`、名称为「空间感增强」的只读空间预设。内置与用户曲线 MUST 使用统一的类型化参数通路，同一时刻只启用一个预设或草稿，EQ 与空间处理不得叠加。响度归一化 MUST NOT 成为预设或载荷变体，MUST NOT 占用「同一时刻只启用一个预设」的位置；它 SHALL 由独立开关控制，并在用户显式开启时作为逐曲增益层与 EQ/空间处理显式叠加（行为由 `loudness-normalization` 规定）。0.2.0 P0 的预设列表 MUST NOT 提供可操作的导入导出、混响或设备绑定入口；P1 的响度归一化入口 SHALL 位于音效浮层的独立区域，不增删九个 EQ 与一个空间预设。系统不宣称恢复音质、环绕声、5.1 或对象音频能力。预设描述 MUST 与实际处理一致，不能将主观调音初值称为通用行业标准曲线，将高频 peaking 称为恢复高频延伸，或将整曲静态 EQ 称为动态去齿音。

空间感预设固定用户 width 为 1.25，不向用户提供 width 编辑。系统可在启用/关闭的内部生命周期中使用 `spatial:m` 在中性 1 与固定目标 1.25 间连续过渡，但必须先用所处分发库的持续 PCM 捕获证明实际输出变化。`af-command` 的返回值不能作为生效证据，`af` 配置描述也不代表运行时实际参数。测量必须在素材仍被处理时发出命令，记录输出样本位置并排除已解码 EOF、加载/seek 重置及预处理缓存的干扰。macOS 的修复证据见 native-gate.md；其他平台须独立验证，不继承 macOS 结论。

#### Scenario: 选择不同类型
- **WHEN** 用户从 EQ 预设切换到空间感增强，再切回 EQ
- **THEN** 每次整体替换处理类型及参数，确认后显示新预设名称，前一种处理被移除

#### Scenario: 内置注册表完整
- **WHEN** 用户离线打开音效列表
- **THEN** 九个 EQ 与一个空间预设均默认可用且不可删除，无账号或会员限制，无「原声」列表项；响度归一化开关不属于预设列表，不改变条目数量

#### Scenario: 归一化与预设显式叠加
- **WHEN** 用户开启归一化后选择任一 EQ 预设或空间预设
- **THEN** 预设仍按原规则整体替换并确认生效，归一化作为独立增益层叠加，不出现两种预设同时生效，也不把归一化显示为已选预设

#### Scenario: 预设描述与能力一致
- **WHEN** 用户查看古典、人声或其他内置预设说明
- **THEN** 说明表达音色取向，不承诺高频信息恢复、动态去齿音或适合所有同类录音/设备，曲线发布前有匹配响度试听依据

#### Scenario: 运行时改参能力不足时不谎报生效
- **WHEN** 某内置预设的滤波参数需要更新，而后端只能通过 `af-command` 发送
- **THEN** 系统先以持续 PCM 前后测量验证当前运行库的参数路径；输出变化未被证明时不能仅凭命令成功宣称该路径可用，不能改为每次输入重建链来绕过连续性验收；用户 width 始终不可编辑

### Requirement: 音效本机持久化及恢复隔离
系统 SHALL 原子保存版本化用户曲线、当前选择/草稿、保留参数、请求启用及 preamp 模式/请求值；拖动合并写入，正常退出刷新最终状态。实际保护增益 MUST 按新环境重算，不能恢复为已生效。此处「音效」特指用户可编辑的音色偏好及其请求状态：它们 MUST 仅存放于本机偏好，不能进入 SQLite、资料库 `echo/`、outbox 或同步载荷，不发起网络请求。旧偏好缺少音效字段 MUST 初始化为关闭且不影响其他有效偏好。

由扫描从媒体内嵌标签派生、按歌曲标识查询的逐曲响度参数属于**资料库元数据**，不是音效偏好；它 SHALL 按 `loudness-normalization` 规格保存在本机查询投影中，不进入资料库 `echo/`、outbox 或同步载荷，不发起网络请求，也不改变用户曲线、草稿、选择与请求启用的持久化语义。归一化开关本身 SHALL 使用独立的版本化本机偏好槽，缺失、损坏或未来版本时回落为关闭，不得借用或改写音效偏好文档。音效屏障实际暂停播放时 MUST 不报告 Playing；不支持环境的旁路过渡 MUST 持续推进至确认完成，失败不得放行首样本。

#### Scenario: 正常重启与后台
- **WHEN** 用户关闭浮层、切页面/曲目、后台关窗或正常退出重启
- **THEN** 草稿和曲线保留，后台播放继续使用同一音效，重启恢复请求后等待环境确认，不自动开始发声

#### Scenario: 损坏或未来数据
- **WHEN** 恢复遇到损坏数据、未知版本、缺失 ID 或非法参数
- **THEN** 关闭处理并提示恢复失败，不阻断基础播放，不覆盖原数据，可恢复曲线被保留；归一化偏好的损坏独立回落为关闭，不牵连音效曲线

#### Scenario: 资料库与离线边界
- **WHEN** 断网后切换资料库、清空队列或播放资料库外临时文件
- **THEN** 用户曲线与全局音效保留，临时文件应用同一音效且不写统计或资料库，音效不产生同步或网络载荷；临时播放项不应用响度归一化，逐曲响度参数也不进入同步载荷

#### Scenario: 两类数据互不串写
- **WHEN** 扫描把新的逐曲响度参数写入查询投影，同时用户正在编辑并保存 EQ 草稿
- **THEN** 音效偏好文档内容不因扫描改变，本机偏好文件中不出现逐曲参数，音频 revision 与音效状态机不因元数据更新而重建
