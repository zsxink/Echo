# Spec Delta

## ADDED Requirements

### Requirement: 封面选图预览必须使用受控尺寸的缩略图

桌面应用 SHALL 在用户选择封面图片后，只把最长边不超过 512 px 的缩略图交给 WebView 作为预览；该尺寸 MUST 与 `cover://` 的详情展示档位一致，缩略图 MUST NOT 放大原图。WebView MUST NOT 为选图预览解码原始尺寸的封面像素，预览的资源占用 MUST NOT 随原图像素量线性增长。

缩略图 MUST 由桌面壳在受控内存边界内生成：MUST 复用既有的 5 MiB 体积上限与 JPEG / PNG / WebP 类型白名单，MUST 在整幅解码之前按容器头声明的尺寸施加预设的内存分配上限，超限 MUST 明确拒绝且 MUST NOT 为超限图片分配像素缓冲。生成过程 MUST NOT 写入封面缓存、资料库或任何磁盘文件，MUST NOT 改变 `cover://` 协议、内容寻址、按需生成与缓存回收语义，MUST NOT 改变设置、替换、恢复自动封面与取消不修改已保存封面的对外语义。

缩略图生成失败时 MUST 明确说明原因、保留名称输入与已保存封面、提供重新选择与取消入口；MUST NOT 以空白或破损图像替换已保存封面，MUST NOT 因预览失败而在提交阶段新增拒绝条件或静默改变已保存封面。

#### Scenario: 大像素图片预览只解码受控尺寸缩略图

- **WHEN** 用户选择一张在 5 MiB 上限内、像素量远超展示尺寸（例如 4000×4000）的封面图片
- **THEN** 预览展示最长边不超过 512 px 的缩略图，WebView 不为该预览解码原始尺寸像素，渲染进程占用不随原图像素量线性增长

#### Scenario: 预览生成不写磁盘

- **WHEN** 用户在编辑歌单对话框选图并展示预览，随后不提交
- **THEN** 封面缓存条目、资料库资产与歌单封面引用均不变化，磁盘上不产生该图片的预览文件

#### Scenario: 超出像素分配上限的图片被拒绝

- **WHEN** 用户选择的图片容器头声明的尺寸超过预设内存分配上限
- **THEN** 系统明确说明图片过大，不为整幅解码分配像素缓冲，保留名称输入与已保存封面，并提供重新选择入口

#### Scenario: 缩略图生成失败可恢复

- **WHEN** 所选载荷无法解码、实际格式与声明类型不一致或容器头无效
- **THEN** 系统说明失败原因，不以空白或破损图像替换已保存封面，名称输入与重新选择 / 取消入口保持可用，且既有提交校验不变

#### Scenario: 小图不被放大

- **WHEN** 用户选择一张最长边小于 512 px 的封面图片
- **THEN** 预览仍按受控路径生成且不被放大，界面状态中不保留该图片的逐字节数组

## MODIFIED Requirements

### Requirement: 封面预览的临时资源必须被回收

编辑歌单对话框产生的封面预览临时资源 MUST 在被替换或对话框卸载时被释放，MUST NOT 随每次选图在渲染进程中持续累积。预览 MUST 继续展示用户当前所选或已保存的封面；预览所依据的图片 MUST NOT 以逐字节数组形式保留在界面状态中。

选图预览 MUST NOT 依赖需要放宽内容安全策略才能加载的临时 URL。预览资源 MUST 是只读的展示档位图像数据：重新选图时 MUST 只保留当前一张预览数据；点击「自动封面」、取消编辑或关闭对话框时 MUST 清除该数据，使预览回到已保存封面或自动封面，且 MUST NOT 修改已保存封面。已保存封面的预览 MUST 继续按详情展示档位读取，已提交封面的载荷编码与回收语义 MUST 保持不变。

#### Scenario: 重新选图释放旧预览资源

- **WHEN** 用户在编辑歌单对话框选择一张封面图片后再次选择另一张
- **THEN** 第一张图片的预览数据不再被界面引用，界面只保留当前所选图片的受控尺寸预览

#### Scenario: 关闭对话框释放预览资源

- **WHEN** 用户关闭编辑歌单对话框
- **THEN** 该对话框产生的封面预览数据全部被释放，已保存封面保持不变

#### Scenario: 预览展示用户所选封面

- **WHEN** 用户在编辑歌单对话框选择一张封面图片
- **THEN** 预览显示该图片的受控尺寸缩略图，且界面状态中不保留该图片的逐字节数组
