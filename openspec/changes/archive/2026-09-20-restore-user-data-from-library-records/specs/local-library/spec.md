## MODIFIED Requirements

### Requirement: 单一资料库根目录与本地持久化

系统 MUST 允许用户选择一个活动资料库根目录，并在本机持久化根目录逻辑 ID、相对路径和歌曲记录；一期同一时刻只能有一个活动根目录。资料库数据库 MUST 只保存在应用数据目录；资料库根目录可保存不含本机路径或凭据的 `echo/` 可携带控制面，但不得把本机绝对路径、数据库文件或凭据作为远端资料的一部分（一期不提供远端同步）。

本机数据库 MUST 是可再生层，而不是用户数据的唯一存放处：对已经具备可携带控制面的资料库，本机数据库丢失、被清空或被另一台设备的数据库替换后，用户重新选择同一根目录 MUST 以该根目录的对象资料为准恢复歌单、收藏、播放统计等用户数据，并复用其中的歌曲标识；不得因为本机没有记录而重新铸造标识，也不得修改该目录的文件。

#### Scenario: 选择根目录并建立资料库
- **WHEN** 用户选择一个可读的目录作为资料库根目录
- **THEN** 系统创建或打开该资料库的本地记录，读取或建立稳定的根目录逻辑 ID，并开始扫描；重启应用后仍使用同一逻辑 ID 和歌曲 UUID；目录不可写时仍允许浏览和播放，但明确禁用导入与删除

#### Scenario: 安全切换活动根目录
- **WHEN** 已存在可用活动根目录且用户选择另一个可读目录
- **THEN** 系统先验证并扫描新目录，成功后才将其设为唯一活动根目录；系统不移动或删除旧目录文件，保留旧根目录的逻辑记录，并在用户重新选择同一路径时复用原逻辑 ID

#### Scenario: 切换根目录失败
- **WHEN** 新目录验证或首次扫描无法建立可用资料库
- **THEN** 系统继续使用此前的活动根目录和可用视图，不用失败配置覆盖原配置

#### Scenario: 本机数据库丢失后重新选择同一目录
- **WHEN** 本机应用数据目录被清除或应用被重装后，用户重新选择此前使用过的同一资料库根目录
- **THEN** 系统识别该目录已具备可携带控制面，按其中的对象资料恢复歌单、我的喜欢与播放统计，复用对象资料中的歌曲标识，并保持该目录内的文件不被移动或改写
