## ADDED Requirements

### Requirement: 歌单与成员事实时间真实性
系统 MUST 复用既有时间字段记录歌单创建的真实系统时刻，并为每个成功创建的歌单成员关系记录真实加入时刻；时间均由后端在对应提交边界生成，不得改变既有追加顺序、成员 UUID 或重复添加语义。持久化值表示绝对时刻；需要呈现时 SHALL 按读取时设备的当前系统时区转换。

#### Scenario: 创建歌单时记录时间
- **WHEN** 用户成功创建一个歌单
- **THEN** 系统在既有歌单创建时间字段中持久化该次提交的真实系统时刻，后续重命名不得改写创建时间

#### Scenario: 加入歌单时记录时间
- **WHEN** 用户成功将歌曲加入一个歌单
- **THEN** 系统与成员 UUID、追加顺序一起在既有成员加入时间字段中持久化该次加入的真实系统时刻

#### Scenario: 重复加入不重写时间
- **WHEN** 用户尝试将已在目标歌单中的歌曲再次加入
- **THEN** 系统不创建成员、不改变位置，也不改写既有成员的加入时间

#### Scenario: 歌单时间按当前时区呈现
- **WHEN** 歌单创建或成员加入时间出现在界面、诊断或导出结果中
- **THEN** 系统以设备当前系统时区表示对应绝对时刻，且不改变歌单及成员的既有顺序
