## MODIFIED Requirements

### Requirement: 桌面音频播放

系统 SHALL 通过桌面 mpv 播放适配器播放资料库中的本地音频，并以歌曲 UUID 解析当前歌曲到资料库文件；播放器实现不得成为共享 Core 的职责。桌面端 MUST 在 macOS、Windows、Linux 各自从平台安装包内解析该平台打包的 libmpv 并建立播放适配器；任一平台无法解析其平台 libmpv 或 ABI 不匹配时，MUST 以明确错误终止播放后端初始化，不得表现为静默闪退或进入不可播放状态。

#### Scenario: 播放资料库歌曲

- **WHEN** 用户从曲库、歌单或播放队列选择可用歌曲播放
- **THEN** 系统将对应本地文件交给 mpv，常驻播放栏显示封面、标题、艺人、时长和播放状态

#### Scenario: 文件不可用

- **WHEN** 当前歌曲文件不存在、根目录不可用或无权访问
- **THEN** 系统不向播放器提交无效路径，显示资料库不可用或文件不可用原因，并按错误跳过规则处理队列

#### Scenario: 平台播放后端缺失

- **WHEN** 某平台的安装包未包含该平台所需的 libmpv，或运行加载到 ABI 不匹配的库
- **THEN** 系统在初始化播放后端时给出明确可读错误（可追溯到日志），终止播放会话建立，而非无提示闪退
