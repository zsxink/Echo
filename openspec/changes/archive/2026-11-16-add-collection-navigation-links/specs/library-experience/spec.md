# Spec Delta

## ADDED Requirements

### Requirement: 歌曲行与歌曲详情中的歌手/专辑链接

歌曲列表行中，当歌曲读取模型提供稳定分组身份时，歌手名与专辑名 SHALL 渲染为语义化的可聚焦链接控件，并具有可读名称（例如“打开歌手 周杰伦”“打开专辑 范特西”）；用户 MUST 能用 Tab 到达并用 Enter/Space 激活。激活链接 MUST 导航到对应歌手或专辑详情，且 MUST NOT 触发该行播放、行选中/多选切换、批量菜单或改变当前选择集；多选模式下链接仍可导航。读取模型未提供 key 的歌手或专辑 MUST 保持纯文本：未知艺人保留既有缺省文本但不可聚焦，缺失专辑保持既有空白，MUST NOT 渲染为链接或按钮。歌曲详情对话框中的歌手与专辑 SHALL 遵循同一规则；激活后 MUST 先关闭详情及打开它的菜单，再完成导航。

#### Scenario: 点击行内歌手链接

- **WHEN** 用户在任意歌曲列表中点击一首歌的歌手名
- **THEN** 系统导航到该歌手的详情歌曲列表，且该行不开始播放、不改变当前歌曲

#### Scenario: 点击行内专辑链接

- **WHEN** 用户在任意歌曲列表中点击一首歌的专辑名
- **THEN** 系统导航到该专辑的详情歌曲列表，且该行不开始播放、不改变当前歌曲

#### Scenario: 键盘激活行内链接

- **WHEN** 用户用 Tab 聚焦行内歌手或专辑链接并按 Enter 或 Space
- **THEN** 系统执行与指针点击相同的导航，且不触发整行的播放快捷键

#### Scenario: 多选模式下链接仍可导航

- **WHEN** 用户处于多选模式并点击某行的歌手或专辑链接
- **THEN** 系统完成导航，当前选择集保持不变，且不打开批量菜单

#### Scenario: 未知元数据保持纯文本

- **WHEN** 歌曲缺少歌手或专辑元数据
- **THEN** 未知艺人文本或空白专辑不可聚焦、不可点击，不呈现链接语义

#### Scenario: 歌曲详情对话框中的链接

- **WHEN** 用户在歌曲详情对话框中点击歌手或专辑
- **THEN** 系统关闭详情对话框及打开它的歌曲操作菜单，并导航到对应详情歌曲列表
