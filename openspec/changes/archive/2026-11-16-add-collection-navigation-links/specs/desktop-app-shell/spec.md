# Spec Delta

## ADDED Requirements

### Requirement: 一次性聚合导航目标与来源记录

应用壳层 SHALL 提供一次性的聚合导航目标通道，使歌曲列表、歌曲详情、常驻播放栏与沉浸式播放器能够请求“切换到歌手/专辑视图并直接打开指定分组”。目标 MUST 携带 Core 提供的稳定分组身份，壳层 MUST NOT 按展示名推导、重新归一或改写 key。目标 MUST 由目标视图在目录数据落地后消费一次并清除；未消费的目标在用户通过侧边栏、应用菜单、歌单回退或其他视图切换离开时 MUST 被清除，MUST NOT 在之后的视图切换中意外打开旧分组。从歌曲链接发起跳转时，壳层 SHALL 记录跳转前的来源视图与歌单身份，供详情返回；该记录 MUST 只表示本次跳转的来源，MUST NOT 构成可前进/后退的浏览历史栈。通过侧边栏或应用菜单直接进入歌手/专辑视图 MUST NOT 产生来源记录。

#### Scenario: 侧边栏切换清除未消费目标

- **WHEN** 歌曲链接设置了一个尚未被目录消费的目标，用户随即通过侧边栏切换到其他视图
- **THEN** 目标与来源记录被清除，之后再次进入歌手或专辑视图不会自动打开旧分组

#### Scenario: 目标只消费一次

- **WHEN** 目录已按目标打开对应详情，用户返回目录后再次切换视图
- **THEN** 系统不会重复打开该目标，目录保持用户当前选择的浏览状态

#### Scenario: 直接进入目录不产生来源记录

- **WHEN** 用户通过侧边栏或应用菜单直接进入歌手或专辑视图，并从目录卡片打开一个条目
- **THEN** 该详情的返回入口回到聚合目录，而不是任何先前的歌曲视图

#### Scenario: 来源记录支持返回

- **WHEN** 用户从全部歌曲、最近添加、喜欢的音乐或某个歌单通过链接进入聚合详情
- **THEN** 壳层保留该来源视图与歌单身份，详情返回时恢复对应视图
