# Spec Delta

## ADDED Requirements

### Requirement: 歌曲读取模型的稳定分组身份

系统 SHALL 在歌曲列表与歌曲详情的读取模型中暴露歌手和专辑的稳定分组身份（key），使界面能够直接请求“打开该歌手/专辑”，而不必按展示名猜测分组。对具有非空原始歌手或专辑元数据的歌曲，key MUST 由 Core 使用与歌手/专辑目录聚合完全相同的规范化规则派生：先取该歌曲在目录聚合中生效的歌手/专辑名称，再经 NFKC、Unicode 默认 case fold 与空白归一。缺失或空白的元数据 MUST NOT 产生可导航 key；此类歌曲在目录中仍按既有缺省值（未知艺人、未知专辑）参与聚合。专辑 key MUST 仅由规范化专辑名称决定，不包含歌手身份；不同歌手的同名专辑 MUST 产生相同 album key。key MUST 是不透明身份，界面 MUST 原样回传，MUST NOT 依据展示名自行推导、重新归一或比较。

#### Scenario: 展示名变体归入同一歌手身份

- **WHEN** 两首歌曲的歌手元数据分别为 `The Beatles` 与 `THE BEATLES`（或存在全角/半角差异）
- **THEN** 两首歌曲获得相同的 artist key，且该 key 与歌手目录中对应条目的稳定身份一致

#### Scenario: 缺失元数据不提供可导航身份

- **WHEN** 歌曲缺少歌手或专辑元数据，或元数据仅含空白
- **THEN** 该歌曲的读取模型不提供对应 key，界面继续使用既有缺省展示值（未知艺人、空白专辑），且不产生可导航目标

#### Scenario: 同名专辑不按歌手拆分身份

- **WHEN** 两位不同歌手各有一张规范化名称相同的专辑
- **THEN** 两位歌手歌曲的 album key 相同，均指向专辑目录中合并后的同一条目

### Requirement: 从歌曲链接进入聚合详情

系统 SHALL 允许用户从歌曲列表与歌曲详情中的歌手/专辑链接切换到对应目录视图，并直接打开该分组的歌曲列表。打开动作 MUST 在目录数据可用后按读取模型提供的 key 精确匹配目标条目，且 MUST 只消费一次；跳转 MUST 清空目录自身的搜索词，来源视图的搜索词 MUST NOT 过滤目标目录。目标在重新扫描后已不存在时，系统 MUST 停留在可用的目录视图，并给出明确、非阻塞的“可能已被移除”反馈，MUST NOT 停留在空白详情或打开其他分组。跳转 MUST NOT 改变播放状态、当前歌曲或播放队列。从链接打开的详情返回时 SHALL 回到跳转前的来源视图（含来源歌单身份）；来源视图的瞬时搜索词不要求恢复。

#### Scenario: 从全部歌曲打开歌手详情

- **WHEN** 用户在全部歌曲列表中激活某首歌的歌手链接
- **THEN** 工作区切换到歌手视图并直接打开该歌手的歌曲列表，目录搜索框为空，且该次激活不开始播放

#### Scenario: 从歌单打开专辑详情

- **WHEN** 用户在歌单成员列表中激活某首歌的专辑链接
- **THEN** 工作区切换到专辑视图并直接打开该专辑的歌曲列表，显示该专辑的歌曲集合

#### Scenario: 目标已被移除时优雅降级

- **WHEN** 用户在链接对应的歌手或专辑因重新扫描而消失后激活该链接
- **THEN** 系统保留可用的歌手或专辑目录视图，提示目标可能已被移除，且不打开空白详情

#### Scenario: 跳转不改变播放

- **WHEN** 用户激活任意歌手或专辑链接
- **THEN** 当前歌曲、播放状态与播放队列保持不变，被点击的行不得开始播放

## MODIFIED Requirements

### Requirement: 从聚合条目浏览歌曲

系统 SHALL 允许用户从歌手或专辑目录条目进入仅包含该条目可用歌曲的歌曲列表，并显示条目的名称、封面与匹配歌曲数量。从目录条目打开的详情 MUST 能通过明确的返回入口回到此前的聚合目录；从歌曲列表或歌曲详情中的歌手/专辑链接打开的详情 MUST 能通过返回入口回到跳转前的来源视图。在聚合目录、来源视图与详情歌曲页之间切换时，当前活动资料库根目录、搜索词和异步结果的归属 MUST 保持正确，旧根或旧条目的迟到结果不得覆盖当前页面。

#### Scenario: 浏览歌手歌曲

- **WHEN** 用户打开一个歌手条目
- **THEN** 系统展示该歌手的可用歌曲、该歌手的当前有效封面和返回歌手目录的入口

#### Scenario: 浏览专辑歌曲

- **WHEN** 用户打开一个专辑条目
- **THEN** 系统展示该歌手与专辑组合的可用歌曲、专辑封面和返回专辑目录的入口

#### Scenario: 切换根目录时聚合请求仍在进行

- **WHEN** 用户切换活动资料库根目录，而旧根的歌手、专辑或详情歌曲请求仍未完成
- **THEN** 系统清除旧根结果，只接收新根的聚合与歌曲结果，且不得显示旧根的封面或歌曲

#### Scenario: 从歌曲链接打开的详情返回来源视图

- **WHEN** 用户从歌单歌曲列表点击专辑名进入专辑详情，随后激活返回入口
- **THEN** 系统回到该歌单视图，而不是专辑目录
