# 6.4 验收证据：目录删除意图（2026-10-25）

## 完成范围

- 删除开始前将本机 `DeleteIntent` 提交到 `echo/state/delete-intents/`，并将目录冻结的 `final_mutation_id` 持久化到 SQLite 删除账本。
- 撤销和恢复先取消目录意图，再恢复可见性。`TrashApplied` 收据存在且撤销窗口到期后，先提交 `Finalized`，再执行 SQLite 逻辑删除；重复恢复使用同一意图和 mutation 身份。
- 已认证的远端增量最终墓碑会先于 SQLite 对象应用 supersede 对应对象的 open 本机意图。无本机删除意图时不创建伪意图。
- resource retention 重建继续保留 pending mutation 的资源声明；catalog 删除及重开数据库不会丢失 hold 或 retained receipt。
- `begin` 对重试校验 object 身份，拒绝把同一 operation UUID 复用于其他对象。每次状态转移使用稳定目录提交身份。
