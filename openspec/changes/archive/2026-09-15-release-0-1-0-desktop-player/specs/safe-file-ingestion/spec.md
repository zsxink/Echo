## Purpose

为 Echo 提供可恢复、不可覆盖原文件的本地导入和系统文件打开能力，确保外部音频及同名歌词在校验完成后安全进入资料库，并让崩溃、重复、重名和资料库不可用时的结果对用户清晰可见。

## ADDED Requirements

### Requirement: 多选导入与默认目标命名

系统 MUST 提供一次选择多个本地音频文件的导入操作，并逐文件处理。每个文件解析标签后，目标目录 MUST 使用 `歌手/歌手 - 歌曲名.原扩展名`；缺少歌手或歌曲名时 MUST 使用可见且确定性的兜底名称（分别为“未知艺人”和“未命名歌曲”），路径组件和文件名 MUST 清理平台禁止字符、控制字符和保留名称，同时保留可辨识性。

#### Scenario: 多选文件成功导入
- **WHEN** 用户选择多个支持格式的外部音频并确认导入
- **THEN** 系统分别解析、复制并返回每个文件的成功、跳过或失败结果，单个文件失败不回滚其他已成功文件

#### Scenario: 标签缺失和非法字符
- **WHEN** 音频缺少歌手/歌曲名或标签包含 `/`, `\\`, 控制字符、平台保留名或过长路径组件
- **THEN** 系统按兜底规则和字符清理规则生成目标路径，截断时仍保留扩展名和可区分的稳定后缀，且不覆盖任何既有文件

### Requirement: 同名歌词侧车导入

若源音频所在目录存在同基础文件名的 `.lrc`（扩展名大小写不敏感），系统 MUST 将其复制到目标目录并使用与目标音频相同的基础文件名；歌词复制失败 MUST 单独报告并不得伪装为完整成功。没有同名 `.lrc` 时不得创建空歌词文件。

#### Scenario: 音频与 LRC 一起导入
- **WHEN** 用户导入 `晴天.flac` 且同目录存在 `晴天.lrc`
- **THEN** 系统将两者复制为同一目标基础名的 `.flac` 和 `.lrc`；扫描后的歌曲仅在没有内嵌歌词时使用该侧车歌词

#### Scenario: LRC 不可读
- **WHEN** 同名 `.lrc` 存在但不可读、是目录或复制校验失败
- **THEN** 系统保留已校验的音频结果，逐文件结果明确标注歌词未导入及原因，不创建损坏或空的目标 `.lrc`

### Requirement: BLAKE3 去重与重名编号

系统 MUST 使用全文件 BLAKE3 判断重复内容。目标位置或资料库中已有相同哈希时 MUST 不复制、不新建歌曲 UUID，并返回已存在记录；目标文件名相同但内容不同 MUST 依次使用 ` (2)`, ` (3)` 等编号，直至找到同时不存在或内容相同的安全目标，绝不覆盖既有文件。

#### Scenario: 内容重复
- **WHEN** 导入文件的 BLAKE3 与资料库已有歌曲相同
- **THEN** 系统跳过音频和相应副本的重复写入，不创建第二条歌曲记录，并告知用户已有歌曲位置/UUID

#### Scenario: 同名不同内容
- **WHEN** 目标已有同名音频但 BLAKE3 不同
- **THEN** 系统生成带最小可用编号的目标名，保留原文件不变，并将新文件作为新歌曲导入

### Requirement: 暂存、校验、原子移动与操作日志

导入 MUST 先写入资料库内部的暂存位置，完成文件大小/可读性、BLAKE3 和必要的元数据解析校验后，才发布音频及其侧车文件；每个文件自身 MUST 通过同文件系统 rename 原子发布，音频是主资源，系统不宣称两个独立目标文件能跨文件原子提交。SQLite 歌曲记录 MUST 仅在音频完整发布后以单个可恢复事务提交。系统 MUST 为每个导入及每个资源记录可恢复的意图态、结果态、路径和预期哈希，禁止产生指向未完成文件的歌曲记录。

#### Scenario: 校验失败不落库
- **WHEN** 暂存文件复制不完整、哈希不匹配、标签解析失败到无法建立歌曲或最终移动失败
- **THEN** 系统不创建歌曲记录，不覆盖目标文件，保留可诊断失败结果并清理或标记暂存文件以便恢复

#### Scenario: 导入成功原子可见
- **WHEN** 暂存音频及同名 LRC（若存在）均通过校验并移动成功
- **THEN** 系统提交歌曲记录、路径和哈希，用户只能看到完整目标文件，不会看到半复制文件作为可播放歌曲

#### Scenario: 崩溃后恢复
- **WHEN** 应用在暂存、移动或 SQLite 提交之间崩溃并再次启动
- **THEN** 系统读取操作日志，补写缺失且已完整落地的记录或回滚未完成文件，清除不可用暂存物；恢复过程可重复且不产生重复 UUID/文件

#### Scenario: 音频发布后侧车失败
- **WHEN** 音频已经完整原子发布，但同名 LRC 在发布前后失败或应用崩溃
- **THEN** 系统允许以同一预留歌曲 UUID 完成音频入库，并恢复、重试或清理 LRC 子资源；结果明确标示歌词失败且不得留下半写侧车

#### Scenario: 发布后 watcher 抢先观察
- **WHEN** 导入已经把完整音频发布到最终路径，但 watcher 在导入数据库提交前观察到该路径
- **THEN** watcher 必须等待活动导入的路径 claim 或复用其预留歌曲 UUID，最终只能产生该预留 UUID 对应的一条歌曲记录

### Requirement: 逐文件结果与资料库不可用反馈

每次导入 MUST 返回与输入一一对应的结果，至少区分已导入、内容重复、名称冲突后导入、跳过、不支持、失败及资料库不可用，并包含用户可执行的错误说明。资料库根目录不可用时 MUST 在开始复制前拒绝整批导入，不得写入源文件或不完整暂存物。

#### Scenario: 混合结果
- **WHEN** 多选批次中包含成功文件、重复文件、不支持文件和权限失败文件
- **THEN** 系统展示每个输入文件的独立状态和原因，成功项仍可播放，用户无需重新处理已成功项

#### Scenario: 导入时根目录断开
- **WHEN** 用户确认导入时资料库根目录已卸载、无权限或不可写
- **THEN** 系统不开始复制，所有输入均返回资料库不可用，保留源文件并提供恢复根目录后重试入口

### Requirement: 源文件、系统关联与安全边界

导入 MUST 复制外部源文件而不移动、删除或修改源文件。系统 MUST 支持将一期音频格式注册为默认打开应用；从系统文件管理器打开资料库外文件时创建仅存在于当前会话的临时播放项，可解析内嵌信息和同名 `.lrc`，但不得写入歌曲表、歌单、播放统计、同步队列或导入暂存目录。

#### Scenario: 外部文件直接打开
- **WHEN** 用户从系统文件管理器双击资料库外的支持音频文件
- **THEN** 系统唤醒或启动 Echo，创建临时播放项并播放，可展示内嵌封面/歌词及同名 `.lrc`，关闭会话后该项消失

#### Scenario: 活动资料库内文件直接打开
- **WHEN** 系统传入的音频路径位于当前活动资料库根目录且可通过相对路径找到已有记录
- **THEN** 系统使用该歌曲已有 UUID 播放，不创建临时项，不复制文件，并沿用其覆盖层、收藏和统计语义

#### Scenario: 非活动旧资料库文件直接打开
- **WHEN** 系统传入的音频路径属于已保留但当前非活动的旧资料库根目录
- **THEN** 系统不得使用旧根 UUID 绕过活动根隔离或静默切换资料库，而是将文件作为当前会话临时项播放并提示可在设置中显式切换资料库；该次播放不使用旧根覆盖层、收藏或统计，也不持久化到队列

#### Scenario: 源文件保持不变
- **WHEN** 导入成功、重复或失败
- **THEN** 系统均不修改源音频或源 `.lrc` 的内容、名称和位置

#### Scenario: 暂存目录名称与用户内容冲突
- **WHEN** 资料库中已经存在类似 Echo 暂存目录名称的用户目录、无效所有权 marker 或符号链接
- **THEN** 系统不得忽略、接管、写入或清理该目录，而应 exclusive-create 带有效所有权 marker 的随机专属目录；无法安全建立时禁用导入和删除

### Requirement: 单实例唤醒与重复打开

系统 MUST 保证同一用户会话只有一个 Echo 实例处理文件关联请求；已有实例收到新路径时 MUST 被唤醒并立即将该路径设为当前播放项。重复传入同一路径不得创建多个实例或持久化临时记录。

#### Scenario: 已运行实例接收文件关联
- **WHEN** Echo 已运行且系统再次双击资料库外音频
- **THEN** 系统唤醒现有实例，将文件设为当前播放项并将窗口置前，不能启动第二个 Echo 进程

#### Scenario: 冷启动文件关联
- **WHEN** Echo 未运行且系统传入一个支持音频路径
- **THEN** 系统先建立单一实例，再创建临时播放项并开始播放；初始化失败时报告错误且不写入曲库

### Requirement: 跨平台路径与恢复后的幂等性

导入目标命名和比较 MUST 在 macOS、Windows、Linux 分别遵循平台路径分隔符、大小写和保留名称规则，并正确处理 Unicode；操作重试、重复监听或恢复任务 MUST 不覆盖文件、不重复复制相同哈希、不产生多条相同歌曲记录。

#### Scenario: 跨平台安全命名
- **WHEN** 外部文件来自任一支持桌面系统，且包含 Unicode、大小写差异或 Windows 保留名称
- **THEN** 系统生成该平台可创建的目标路径，重新扫描得到稳定相对路径和唯一歌曲记录

#### Scenario: 重试导入幂等
- **WHEN** 用户对同一输入重试，或崩溃恢复后再次执行同一操作
- **THEN** 系统按 BLAKE3 和操作日志识别已完成结果，返回重复/已完成状态，不覆盖既有文件、不新增重复歌曲
