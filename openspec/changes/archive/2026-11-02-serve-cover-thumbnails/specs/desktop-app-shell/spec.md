# Spec Delta

## ADDED Requirements

### Requirement: 封面资产协议必须按显示档位提供受控图像

桌面应用 SHALL 继续通过只读的 `cover://` 协议按不透明内容寻址 key 提供封面，并允许请求携带显示档位：缺省或 `s=list` 返回最长边不超过 128px 的列表缩略图，`s=detail` 返回最长边不超过 512px 的详情缩略图，`s=original` 返回原始字节。缩略图 MUST NOT 放大原图。缺省档位 MUST 为 `list`；无法识别的 `s` 值 MUST 回落到 `list`，不得回落到原图。

协议 MUST 在剥离 query/fragment 之前解析档位，档位 MUST NOT 参与 key 白名单校验、key 长度计算或文件系统路径构造。key 白名单、长度上限、未知或畸形 key 的 404 行为、CSP，以及既有的 `Access-Control-Allow-Origin` 像素读取白名单与 `Vary: Origin` MUST 保持不变。

缩略图 MUST 按需生成、原子落盘并在后续请求中复用；原图不可解码或生成失败 MUST NOT 以半成品替换既有文件。缩略图 MUST 维持现有 JPEG 输出；透明原图的 alpha 在缩略图中不被保留，这是既有行为，本 change 不得改变。

#### Scenario: 列表类视图请求 128px 档

- **WHEN** 歌曲行、歌单卡、目录卡片、歌曲菜单、播放条或队列面板请求封面
- **THEN** 响应为最长边不超过 128px 的缩略图，且该缓存条目下存在对应的 `thumb-128.bin`

#### Scenario: 歌单封面预览请求 512px 档

- **WHEN** 歌单编辑对话框预览已保存封面
- **THEN** 响应为最长边不超过 512px 的缩略图，且该缓存条目下存在对应的 `thumb-512.bin`

#### Scenario: 沉浸式播放器显式请求原图

- **WHEN** 沉浸式播放器请求当前歌曲封面
- **THEN** 请求携带 `s=original`，响应字节与原始封面一致，且基于该 URL 的主色提取仍能读取像素

#### Scenario: 缺省或未知档位安全回落

- **WHEN** 请求没有 `s` 参数，或 `s` 不是 `list`、`detail`、`original`
- **THEN** 协议按 `list` 档处理，绝不返回原图

#### Scenario: 档位不得绕过 key 校验

- **WHEN** 请求试图把路径片段、超长内容或第二个 key 放入 `s` 参数，或把 `s` 参数放入 key 路径
- **THEN** key 仍按既有白名单和长度上限校验，畸形或未知 key 返回 404，档位参数不影响 key 解析或文件系统访问

#### Scenario: 封面响应可长期缓存

- **WHEN** 协议成功返回原图或任一档位缩略图
- **THEN** 响应包含 `Cache-Control: private, max-age=31536000, immutable`，且 CSP 与既有跨域像素读取授权不变

#### Scenario: 缩略图失败不产生半成品

- **WHEN** 原图不可解码，或缩略图写入被中断
- **THEN** 后续请求不会读到截断的缩略图，原图仍可通过 `s=original` 读取

#### Scenario: 旧缓存条目按需补齐

- **WHEN** 缓存条目只有原图、首次请求某一档缩略图
- **THEN** 该请求生成并原子落盘缩略图，后续同档请求直接复用，不重复解码

### Requirement: 首访缩略图生成不得阻塞 WebView 主线程

封面缩略图的读取、解码、缩放与落盘 MUST NOT 在 WebView 主线程执行；首访尚未生成缩略图的封面时，界面 MUST 保持可交互。同一 key 与同一档位在生成成功时 MUST 合并为一次解码与缩放，其余请求 MUST 复用已落盘结果。生成失败时生成闸门 MUST 被释放，后续请求 MAY 重试；任何路径 MUST NOT 产生重复的半成品文件、死锁或损坏响应。

#### Scenario: 首访缩略图不占用主线程

- **WHEN** 列表首次请求一个尚未生成缩略图的封面
- **THEN** 协议回调不执行 Lanczos3 解码，缩略图在工作线程生成后通过响应返回，期间主线程可继续处理其他请求

#### Scenario: 同一封面的并发首访只生成一次

- **WHEN** 歌曲行、播放条和队列面板同时请求同一封面的同一档位
- **THEN** 只发生一次解码与缩放，其余请求复用同一 `thumb-*.bin` 结果，不产生重复临时文件

#### Scenario: 生成失败不阻塞后续请求

- **WHEN** 首访生成因原图不可解码或写入失败而失败
- **THEN** 发起请求得到失败响应，生成闸门被释放；等待者或后续请求可以重试并同样失败，不会死锁，也不会留下可被读取的半成品
