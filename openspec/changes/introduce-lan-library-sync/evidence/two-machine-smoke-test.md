# Mac + Windows 局域网双机冒烟验证

这份步骤用于验证首次配对和一首音频的单向同步。运行前先备份测试目录；此版本不应用于唯一副本。

## 安装

- Mac：安装仓库打包出的 `target/release/bundle/dmg/Echo_0.3.0_aarch64.dmg`，把 Echo 拖到 Applications。
- Windows：从本次 GitHub Actions `Release` 工作流的 `echo-windows` artifact 解压并运行其中的 0.3.0 `.exe`。
- 这两个包当前未做开发者签名：macOS 若拦截，先在 Finder 对 Echo.app 点按右键 →“打开”并确认；Windows 可能显示未知发布者提示。只运行本仓库本次构建的包。
- 两台电脑连接同一个可信局域网。Windows 首次启动如弹出防火墙提示，只允许专用网络访问。
- 两台设备各自先在 Echo 中选择资料库。主机使用一个测试资料库；Windows 加入设备使用一个空资料库目录。不要选择含有现有音乐的目录作为首次加入目录。

## 配对

1. 在 Mac 打开“设置 → 局域网资料库同步”，选择“主机”，输入 Mac 的局域网 IPv4 地址（例如 `192.168.1.20`），点击“启动主机”。状态应显示“正在作为主机运行”。
2. Mac 点击“生成主机邀请”，复制邀请文本。邀请短时有效，不要贴到公开位置。
3. 在 Windows 同一设置页选择“加入设备”。填入 Mac 地址和邀请文本，填写设备名称，点击“请求加入”。若自动发现可用，也可点“搜索局域网主机”后选择主机地址。
4. 回到 Mac 点击“刷新请求”，确认设备名称后点击“批准”。
5. Windows 点击“检查并领取连接”。完成后状态应显示已连接；若显示未连接，先确认两机同网段、主机仍运行且地址/防火墙可达，再重新请求配对。

## 同步一首测试音频

1. 在 Mac 的测试资料库导入一首短音频，等待本地导入完成。
2. 在 Windows 点击“立即同步”。等待状态退出“正在同步”，检查该歌曲出现在 Windows 资料库并可播放。
3. 在 Windows 导入另一首不同的短音频，再点击“立即同步”；回到 Mac 检查它出现并可播放。
4. 记录两端应用版本、操作系统、同步状态、是否出现歌曲和媒体文件，以及任何错误文本。出现问题时保留日志和测试目录，不要反复删除/重建真实资料库。

## 当前证据边界

本地自动化覆盖配对状态机、HTTP/TLS 契约、空库首次登记、资源传输及主机发布从设备上传的音频。以上 Mac + Windows 实机步骤尚未由维护者执行；通过这些步骤之前，不应将真实设备互通标记为已验证。并发修改、断网重试、删除恢复、睡眠/网卡切换也不属于本冒烟测试。
