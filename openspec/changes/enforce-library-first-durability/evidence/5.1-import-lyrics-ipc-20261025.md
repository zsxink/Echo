# 5.1 Import lyrics partial success through IPC and UI

Date: 2026-10-25

## Behavior

- Core already distinguishes a successful audio import from a failed optional same-basename `.lrc` sidecar.
- `ImportResultDto` now carries `LyricsImportResultDto` for `imported` and `savedPending` outcomes.
- Tagged enum fields serialize as camelCase, matching the generated TypeScript contract (`relativePath`, including nested lyrics paths).
- The UI keeps the audio result successful, counts the lyrics failure in the batch summary, and opens the per-file result dialog for that partial success. It displays the audio path and the user-safe lyrics failure reason together.
- Result rows retain their input batch order. A saved-pending audio outcome can also report its lyrics sidecar failure without losing its recovery identity.
