## ADDED Requirements

### Requirement: macOS 菜单栏传输控制与应用身份
系统在 macOS SHALL 提供 Echo 菜单栏状态项；用户打开该状态项时，控制面 MUST 以单行横向顺序展示“上一首、播放/暂停、下一首”三个可点击图标按钮，视觉结构与需求参考图一致，不得退化为三个纵向文字菜单项。控制状态与桌面播放会话一致，每个图标按钮 MUST 具有可访问名称。所有打包产物及原生可见身份 MUST 使用精确名称 `Echo`，不得显示 `echo`。

#### Scenario: 从菜单栏控制传输
- **WHEN** Echo 在 macOS 运行且用户从菜单栏状态项触发播放/暂停、上一首或下一首
- **THEN** 系统只执行一次等效播放控制，并同步更新状态项与主窗口播放栏

#### Scenario: 状态栏控制视觉验收
- **WHEN** 用户点击 macOS 菜单栏中的 Echo 状态项
- **THEN** 弹出的控制面以横向单行按“上一首、播放/暂停、下一首”顺序显示三个图标按钮，按钮可点击且不显示为纵向文字命令列表

#### Scenario: 打包后的身份显示
- **WHEN** 用户在 macOS 中查看 Echo 的应用包、窗口、原生菜单或菜单栏入口
- **THEN** 每个面向用户的名称均为 `Echo`
