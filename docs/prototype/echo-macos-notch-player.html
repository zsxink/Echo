纯黑表面与硬件刘海连成一体，收缩态只比刘海宽左右各 26 px（刚好放一张 16 px 小封面与一组 12 px 跳动音符），整条区域（含刘海本体）都是悬浮展开命中区；展开时向右拓宽、向下展开，面板本体切到液态玻璃（半透明 + 背景模糊 + 顶部高光）。面板顶部两角不内收，而是向屏幕外翻出 26 px 凹圆角，像从屏幕边缘长出来；底部两角仍为 24 px 圆角。面板本身即玻璃：半透明 + 背景模糊 + 顶部高光，没有额外的背景层。

两态结构与复用点

收缩态238 × 32 px 纯黑表面 = 186 px 硬件刘海 + 左右各 26 px。左：16 × 16 封面缩略图；右：12 × 12 跳动音符。播放中跳动，暂停即静止。
展开态360 × 196 px 面板，底部两角 24 px 圆角，顶部两角向屏幕外翻 26 px 凹圆角（与面板同材质的两个 mask 方块）。液态玻璃：半透明黑底 rgba(11,13,19,.86) + backdrop-filter: blur(26px) saturate(160%) + 顶部高光渐变 + 外投影。内容：48 × 48 封面 + 歌曲名称 + 歌手 + 跳动音符；4 px 轨道、12 px 拖动点的进度条；喜欢 / 上一首 / 播放·暂停 / 下一首 / 播放模式。
动效展开 520 ms、收起 420 ms，均用 cubic-bezier(.65,0,.35,1)（两端都缓、无回弹）；面板内容延后 140 ms 交叉淡入；窄耳收起时延后 340 ms 再出现。曲线选择有逐帧依据：easeOutQuint 在 80 ms 内走完约 90% 行程，剩下时间几乎不动，读起来就是「一下弹开」。减少动画下全部退化为即时。
音符逐字复用 .playing-bars 三根条与 .is-playing 门控（library.css:75-83）；减少动画下静止但保留状态。
进度条复用 PlayerProgress.tsx 的 range + seek 语义；拖动期间保持展开，不误收起。
控制复用 PlayerBar.tsx 的 player_control / set_favorite 与 MODES 三态：列表循环 → 随机播放 → 单曲循环。
封面演示用原创抽象 SVG，实际实现走 assetUrl(key, "list") 尺寸受控档与按 key 缓存，不读取原图。

需要你给结论（对应 #147）

  • Q3：表面改为纯黑（与硬件刘海连成一体），深色壁纸下几乎不可见、浅色壁纸下边界清楚。是否需要在深色壁纸下补一条极淡的边缘提示（当前只靠顶部高光渐变 + 外投影，展开态已刻意不画 1 px 内描边，否则会在外翻角接缝处留一道竖线）。
  • Q4：已定为「整条收缩态（含刘海本体）都是悬浮命中区」；仍待定的是仅悬浮展开还是允许点击锁定，展开后右上角的「︿」是收起入口。
  • Q2：与菜单栏状态行（#37，右上示意）并存的间距与让位规则。
  • Q6：空播放态、临时播放项（「临时」标签 + 喜欢禁用）的展示口径。
  • Q8：独立原型文件是否纳入 extract-prototype-css.mjs 的样式生成流程；面板的玻璃参数（透明度 / 模糊半径 / 高光）要不要反过来作为 #74 liquid glass 的 L2 浮层基准。
