# Echo 视觉基准

来源：`c912806cc463266fde4e9de00ca23ddd.jpg` 的珊瑚玫红图标与 `47d7bd80bc0e716c4a2a463aa7a88ced.jpg` 的深钴蓝参考。以桌面原型为准：默认主题为珊瑚玫红，并提供深钴蓝与松石绿两种可选主题；以下以 OKLch 作为实现基准。

```css
:root {
  --bg: oklch(1 0 89.88);
  --surface: oklch(0.9642 0 89.88);
  --fg: oklch(0.2134 0 89.88);
  --muted: oklch(0.5100 0.0160 19.38);
  --border: oklch(0.8940 0.0090 19.38);
  --accent: oklch(0.6528 0.2219 19.38);
}
```

> 实现注记：`--muted` 以实际实现（较取样略加深至 0.51 L）为准，以保证正文/弱化文字在白底 ≥4.5:1；松石绿主题 `--accent = oklch(0.54 0.1330 159.56)`，深钴蓝 `--accent = oklch(0.3787 0.1953 263.35)`。

- 显示字体：`"Ant Sans", "Alibaba PuHuiTi", Inter, Arial, sans-serif`
- 正文字体：`"Ant Sans", "Alibaba PuHuiTi", Inter, Arial, sans-serif`
- 等宽字体：`"SF Mono", ui-monospace, Menlo, monospace`

视觉规则：

1. 近白的背景与纯白表面建立克制、安静的应用工作区。
2. 珊瑚玫红用于默认主题的音乐符号、主要动作、选中与键盘焦点；深钴蓝 `oklch(0.3787 0.1953 263.35)` 与松石绿 `oklch(0.6268 0.1330 159.56)` 均为可切换主题色。
3. 选中态使用与当前主题匹配的极浅色背景与主题色文字，而不是增加额外装饰。
4. 图标保持纯白底与高对比、完整连贯的八分音符轮廓，并适配小尺寸。
5. 主题仅改变音乐符号与主要操作色；所有应用背景保持纯白。用户选择在本机持久化；收藏心形独立使用红色语义（未收藏为空心，已收藏为实心）。
6. 珊瑚玫红主题从 `c912806cc463266fde4e9de00ca23ddd.jpg` 的图标主体采样，使用 `oklch(0.6528 0.2219 19.38)` 作为实色实现。
