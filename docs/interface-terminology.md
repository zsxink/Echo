# Echo 界面术语

本文件定义 Echo 桌面播放器原型的界面区域与控件名称，供产品讨论、设计评审与开发实现统一使用。

## 整体结构

| 术语 | 定义 | 包含内容 |
| --- | --- | --- |
| 应用框架 | Echo 的整体界面容器。 | 侧边导航栏、资料库工作区、常驻播放栏。 |
| 侧边导航栏 | 位于应用左侧，用于切换资料库视图和歌单，以及访问应用级工具。 | 品牌区、资料库导航、歌单导航、应用工具区。 |
| 资料库工作区 | 位于应用中央的内容工作区域。 | 工作区顶栏、资料库工具栏、歌曲列表。 |
| 常驻播放栏 | 固定在应用底部，始终提供当前播放与基础控制。 | 播放进度条、当前播放区、传输控制区、音频与队列区。 |

## 侧边导航栏

| 术语 | 定义 |
| --- | --- |
| 品牌区 | 显示 Echo 标识与产品名称的区域。 |
| 资料库导航 | 切换“全部歌曲”“最近添加”“喜欢的音乐”等资料库视图的导航组。 |
| 歌单导航 | 显示与进入用户歌单的导航组，包含新建歌单操作。 |
| 应用工具区 | 位于侧边导航栏底部的同步、主题和设置入口。同步按钮为二期功能，一期不提供可操作同步。 |
| 主题色菜单 | 由主题入口展开的选择菜单；提供珊瑚玫红（默认）、深钴蓝、松石绿三种主题，并记住本机选择。 |

## 资料库工作区

| 术语 | 定义 |
| --- | --- |
| 工作区顶栏 | 资料库工作区顶部的全局操作区域。 |
| 搜索 | 按歌曲、艺人或专辑检索本地资料库的输入控件。 |
| 导入 | 将音乐文件加入 Echo 自管资料库的主要操作。 |
| 资料库工具栏 | 歌曲列表上方的当前视图信息与列表操作区域。 |
| 排序方式 | 一期“全部歌曲”的排序控件，依次提供最近添加、歌曲名称、艺人、播放次数。 |
| 全选歌曲 | 原型中的歌曲全选控件；其批量操作与业务逻辑属于二期，当前不实现。 |
| 歌曲列表 | 以表格展示本地歌曲并提供单行歌曲操作的主内容区域。 |
| 搜索空状态 | 没有匹配歌曲时显示的说明与清除搜索操作。 |

## 常驻播放栏

| 术语 | 定义 |
| --- | --- |
| 播放进度条 | 位于资料库工作区与常驻播放栏交界处、横跨窗口的播放定位控件。 |
| 当前播放区 | 显示当前歌曲封面、歌曲信息与收藏操作的左侧区域。 |
| 传输控制区 | 位于播放栏中部，包含收藏、上一首、播放/暂停、下一首和播放模式。播放模式在顺序播放、随机播放、单曲循环之间切换。 |
| 音频与队列区 | 位于播放栏右侧，包含静音、音量滑块、播放队列和展开播放器。 |
| 音量滑块 | 使用主题色显示已设定音量比例、支持拖动调节的控件。 |
| 静音开关 | 用于在当前音量与最近一次非零音量之间切换的按钮。 |

## 覆盖层与反馈

| 术语 | 定义 |
| --- | --- |
| 沉浸式播放器 | 展开后覆盖主界面的当前歌曲播放视图，包含唱片视觉、歌曲元信息、歌词和收起操作。当前歌词行随播放进度定位。 |
| 歌词专注阅读 | 在沉浸式播放器中展开歌词的阅读状态；再次操作或使用收起按钮可退出。无歌词时显示空状态。 |
| 播放队列面板 | 显示待播放歌曲并支持清空队列的浮层。 |
| 歌曲操作菜单 | 对单首歌曲进行下一首播放、歌单操作、查看详情、打开目录和删除的上下文菜单。 |
| Toast 提示 | 非阻塞的短时操作反馈，包含 Echo 图标与单行提示文本。 |

## 窄屏与浮层交互

| 术语 | 定义 |
| --- | --- |
| 窄屏侧边栏 | 窗口宽度不超过 760px 时由菜单按钮开合的侧边导航栏；展开时显示遮罩，点击遮罩可关闭。 |
| 浮层关闭 | 主题菜单、排序菜单、歌曲操作菜单与播放队列支持点击外部关闭；按 Escape 按既定优先级关闭当前最上层界面。沉浸式播放器使用收起按钮或 Escape 关闭。 |

## 命名约定

- 使用“常驻播放栏”，不使用“下面功能区”或“播放器控制栏”泛称。
- 使用“播放进度条”，不使用“音乐调节”。
- 使用“音频与队列区”描述音量、队列与展开播放器所在的右侧区域。
- 使用“传输控制区”描述上一首、播放/暂停、下一首等曲目控制；“播放控制”仅作为其简称。
