# Echo 总体规划

> 状态：规划中  
> 更新时间：2026-09-26

## 目标

Echo 按“桌面本地体验 → 局域网同步 → Android → 远程存储同步 → iOS”的顺序演进。每一阶段都应交付一个可独立使用、可验证的版本；后续阶段复用既有的 Rust Core、资料库模型和传输无关的同步协议，而不重写播放器核心。

## 阶段总览

| 阶段 | 主题 | 主要交付 | 完成标志 |
|---|---|---|---|
| 一期 | 完整桌面版播放器 | macOS、Windows、Linux 上可日常使用的本地音乐播放器 | 可稳定导入、管理、搜索和播放本地曲库 |
| 二期 | 局域网同步 | 桌面端局域网同步主机与可复用的同步核心 | 两台桌面设备可在局域网内可靠双向同步同一资料库 |
| 三期 | Android | Android 客户端连接局域网主机，管理、同步和播放资料库 | Android 可在局域网连接桌面端，并支持离线浏览与播放已下载歌曲 |
| 四期 | 远程存储同步 | MinIO / S3 等对象存储连接器 | 桌面与 Android 可通过远端汇聚点同步同一资料库 |
| 五期 | iOS | iOS 原生体验与既有资料库同步 | iOS 可连接局域网主机或远程存储，管理、同步和播放资料库 |

## 一期：完整桌面版播放器

### 范围

- 支持 macOS、Windows、Linux。
- 选择并扫描本地音乐资料库根目录，解析歌曲标签、封面与歌词；不复制或移动用户原始文件。
- 通过导入按钮将新歌曲复制入资料库的 `media/`，并按默认的 `media/歌手/歌手 - 歌曲名.扩展名` 规则组织文件；`echo/` 是版本化控制面，`echo/tmp/` 仅用于可恢复导入暂存。
- 监控资料库目录变化，提供手动重新扫描；资料库根目录不可用时清晰提示并暂停相关操作。
- 重新打开（含清除应用数据或换机后重新选择）同一资料库目录时，先按 `echo/` 对象资料接续歌曲 UUID、我的喜欢、歌单与成员顺序、播放统计，再扫描 `media/`；验收口径是「从此不再丢失」——本机 SQLite 只是可重建的投影，历史目录中从未落盘的歌单不在恢复范围内。
- 安全导入与文件关联：重名且内容相同则不重复导入，重名但内容不同则自动追加编号且绝不覆盖已有文件；文件移动或改名后仍保留歌曲 UUID。
- 支持从系统文件管理器双击音频文件直接播放；资料库外文件以临时播放方式打开，不加入资料库、不计入同步。
- 为一期后的歌曲编辑固化数据规则：仅保存到 Echo 使用覆盖层；写回歌曲文件会更新内嵌元数据并清除对应覆盖层。
- 曲库浏览、搜索、排序、收藏、播放列表与歌单 CRUD。
- 稳定的播放队列、播放控制、进度、音量和快捷键。
- 沉浸式黑胶播放器、歌词显示与无歌词状态。
- 主题、窗口布局和本机偏好设置。

### 不包含

- 资料库同步与可操作的同步入口。
- 全选及批量操作。
- Android 与 iOS 客户端。

### 验收标准

用户可在任一支持的桌面系统中完成“导入或扫描音乐 → 搜索或浏览 → 播放 → 建立歌单 → 下次启动继续使用”的完整日常流程，且不依赖网络或账号；资料库外音乐可由系统双击直接临时播放，不会被加入资料库。

## 二期：局域网同步

### 范围

- 建立传输无关的同步核心，复用一期已有的版本化对象资料、outbox、设备 ID、HLC、墓碑与恢复边界。
- 桌面端可作为局域网同步主机，为其他 Echo 设备提供资料库同步服务。
- 客户端保有自己的 SQLite 投影和本地同步队列；主机作为资料库的局域网汇聚点，不通过共享或覆盖 SQLite 文件同步。
- 支持首次同步与后续增量同步，在局域网内传输对象资料和媒体文件。
- 同步歌曲记录、封面、歌词、覆盖层、收藏状态、歌单、删除墓碑和必要的同步元数据。
- 支持多设备产生变更并汇聚到主机，再传播到其他设备；离线期间的本地变更在重新连接后继续同步。
- 提供主机连接状态、同步进度、错误反馈、重试和冲突处理。
- 以全文件 BLAKE3 哈希识别歌曲，以版本号和墓碑传播修改与删除。
- 定义局域网服务的设备发现或地址配置、设备配对及访问控制方式。

### 不包含

- MinIO、S3、WebDAV 等远程存储连接器。
- 流式播放。
- 将 SQLite 数据库文件作为同步载荷。

### 验收标准

两台桌面设备连接同一局域网主机后，任一设备对资料库、歌单、收藏或删除的修改均能在其他设备可靠可见；断网期间产生的修改可在恢复连接后汇聚；冲突、失败和同步进度对用户清晰可见。

## 三期：Android 版本（局域网连接）

### 范围

- 以 Flutter 构建 Android 客户端，通过 flutter_rust_bridge 复用 Rust Core、同步核心和局域网连接协议。
- Android 可发现或手动连接局域网内的桌面同步主机，并完成设备配对。
- 支持曲库、搜索、歌单、收藏、封面、歌词和本地播放。
- 使用 media_kit 提供播放能力，并适配通知栏、锁屏控制与后台播放。
- 支持局域网首次同步、增量同步、离线期间的资料库浏览，以及已下载歌曲的离线播放。
- 在本阶段明确手机端媒体文件的下载范围、存储位置、空间提示和删除缓存行为。

### 验收标准

Android 用户可连接局域网内的桌面主机，浏览并管理资料库，在手机本地播放已下载歌曲；手机端的收藏、歌单等修改可离线暂存并在重新连接后与桌面端汇聚一致。

## 四期：远程存储同步（MinIO / S3）

### 范围

- 为同步核心实现 MinIO / S3 兼容对象存储连接器，复用局域网阶段验证过的同步规则与对象格式。
- 支持首次同步、增量同步、媒体文件传输、重试、冲突处理和同步状态反馈。
- 支持桌面与 Android 设备连接同一远端汇聚点；每份资料库仍只绑定一个活动远端。
- 远端连接器不改变本地 SQLite 投影和本地优先行为。

### 验收标准

桌面与 Android 设备连接同一 MinIO / S3 兼容远端后，可可靠同步资料库、歌单、收藏、删除和媒体文件；离线期间的修改在恢复连接后可继续汇聚，失败和冲突状态清晰可见。

## 五期：iOS 版本

### 范围

- 以 Flutter 构建 iOS 客户端，复用 Rust Core、同步核心和既有连接器。
- 对齐 Android 与桌面端的曲库、歌单、收藏、歌词和播放核心体验。
- 适配 iOS 的媒体权限、后台播放、锁屏控制与系统音频会话。
- 支持局域网主机或 MinIO / S3 兼容远端的资料库同步和离线播放。

### 验收标准

iOS 用户可连接同一局域网主机或远端汇聚点，完成稳定的同步、管理和播放；跨桌面、Android、iOS 的资料库数据保持一致。

## 跨阶段约束

- Rust Core 负责资料库、导入、索引和同步；不依赖 UI 或音频播放器。
- 本地资料库使用 SQLite；跨设备同步传输 JSON 变更记录和媒体文件，不同步 SQLite 数据库文件本身。
- 音频播放保持平台适配：桌面使用 mpv / libmpv，移动端使用 media_kit。
- 一期固化离线的版本化对象资料、outbox、设备 ID/HLC 与恢复边界，但不建立网络连接或同步 UI；二期先实现局域网传输，三期接入 Android，四期再增加 MinIO / S3 远端连接器。
- 每期开始前确认范围、验收标准和回归测试；未完成当前阶段的验收，不进入下一阶段。

## 0.1.0 已封版项（macOS 已验证；三平台 libmpv 基座落地、人工冒烟待扩展）

0.1.0 以 macOS 单平台验证为基线封版；后续 change 持续交付三平台能力。**`introduce-windows-linux-libmpv`**（已归档至 `openspec/changes/archive/2026-09-26-introduce-windows-linux-libmpv`）已落地 Windows/Linux 的 libmpv 装载基础（`bundled_libmpv` 三平台分支、build.rs dev 部署、NSIS/AppImage/deb bundle 布局）与平台 Gate（9.7 正式校验 + 9.8 三平台真机 load/ABI/command、Windows WebView2 报告），并随打包附带三份许可证说明。**`scope-platform-bundle-resources`**（同目录归档）修正了平台无关 `bundle.resources` 导致 Windows DLL 外溢进 macOS dmg 的缺陷，macOS 侧已实测（dmg 66.7 MB → 15.7 MB，产物无外来平台二进制）并加入 Gate 断言。以下人工冒烟与发布期校验仍留待后续 change。

- 9.8 三平台候选安装包：macOS 12+ universal、Windows 10 22H2/11 x64、Ubuntu 22.04 AppImage/deb 启动、播放、托盘、文件关联和显式退出验证。
- 13.2 原生端到端临时资料库流程三平台数据、UUID、队列和偏好一致性验证。
- 13.3 故障注入矩阵：journal 状态写/FS 调用/DB commit 前后强制终止重启、watcher 抢占/暂存目录清理/卷断开注入、恢复矩阵验证。
- 13.4 watcher 乱序/丢失、根目录卸载/恢复、权限撤销、只读根、Unicode/长路径和外部改名移动矩阵验证。
- 13.5 真实 libmpv、文件关联冷/热启动、后台关窗、托盘/媒体键、reveal/回收站三平台人工冒烟。
- 13.7 CI 三平台打包：macOS notarized DMG、Windows 安装包、Linux AppImage/deb，全新/覆盖安装、卸载、libmpv 装载、checksum 和许可证。
- 13.9 完整场景校验：166 个场景 + PRD A1–A14 全覆盖。
- 13.10 README、架构/开发/测试/打包/故障恢复文档、第三方 notices 和 strict validate。

## 一期后的待立项功能

- 可配置导入文件名与目录格式。
- 新增文件目录视图，用于按资料库中的实际目录结构浏览歌曲。
- 歌曲编辑：在资料库根目录内移动歌曲，并编辑写回音频文件内嵌的歌词、封面和元数据；移动保持歌曲 UUID 不变，写回后重新扫描并更新哈希。
